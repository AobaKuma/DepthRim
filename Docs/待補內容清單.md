## 3. 功能（還沒做）

### M4 聲納
- 被動聲納「聽見推進器噪音」：讓被動聲納對推進中的敵方潛艇有加成（4.3 留下的）。

### M6 跳幫
- **奪船：** 清空海盜潛艇船員後收為己用，而不是離開時鑿沉。
- **贖回俘虜：** 俘虜被突擊艇帶走後，目前只進原版的綁架追蹤，沒有專屬的贖回任務。
- **突擊艇的航程與耗能：** 目前固定 8 格海路，不吃燃料、不吃電。
- **失蹤殖民者的打撈：** 因破口失蹤的殖民者（§2）之後要有打撈／救援事件找回。

### M7 敵方勢力
- **7.5 海盜基地：** 固定的海洋據點，有 DMSE 抽象防空、基地地圖（海床上的密閉艙室群），會派突擊艇與魚雷。
- **魚雷打已生成地圖的海盜潛艇：** 目前被跳幫中的潛艇有地圖，魚雷照一般流程落在地圖上，不扣世界層的船殼耐久。

### M8 終局（整段未開始）
- 深處信號、沉睡星艦、下錨修復與啟動期間的連續襲擊（§7）。

### 雜項
- 深海科研點數。
- 航程估算計入推進器以外的用電與船上發電機。

## 4. 已知限制與待調整

| 項目 | 說明 |
|---|---|
| 跳幫襲擊裡的動物與機械族 | 敵方陣營的戰鬥群會帶動物（例如野豬）或 DMS 機械族上艇；機械族不發潛水服，動物在水中會溺水 |
| 突擊艇預警時間 | 主動聲納對突擊艇的預警窗口約 2900 tick（48 遊戲分鐘），是把突擊艇的 `distanceLevel` 設成 0.4 調出來的，要實際玩過再定 |
| 艙內戰鬥打傷牆 | 襲擊者在艙裡開火會打傷牆、照常滲水（測試看到 3% 水位、3 面受損牆），這是預期行為，平衡要再看 |
| 海盜潛艇數值 | 船殼 400、高爆魚雷 110（4 發沉）、4 枚攔截彈每天補 2、每 1～3 天發射 1～2 枚、船員點數至少 500，都是初值 |
| 聲納分類距離 | 偵測半徑的一半；主動聲納 7.5 格，所以 3.75 格內才分得出來 |
| 跳幫襲擊頻率 | 第 10 天起，每張開著主動聲納的海洋地圖平均 12 天一次 |
| 原版的開局威脅保護 | 原版在新流浪者之後 300000 tick 內擋掉所有 ThreatBig（預設值讓開局 3.3 天內都擋），驗收測試要用 `CanFireNowSub` 加 forced |
| 雙色衣物 | 衣物在水中會失去第二色（§2.1） |
| 變溫層中層水域 | 變溫層不挖深淵，所以看不到中層水域生物，要等潛艇航行地圖或改挖深淵 |
