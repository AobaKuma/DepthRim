## 3. 功能（還沒做）

### 戰鬥與敵方（M4、M6、M7）
- **被動聲納「聽見推進器噪音」**：對推進中的敵方潛艇有加成。
- **7.5 海盜基地**：固定的海洋據點，有 DMSE 抽象防空、海床上的密閉艙室群地圖，會派突擊艇與魚雷。
- **奪船**：清空海盜潛艇船員後收為己用，而不是離開時鑿沉。
- **魚雷打已生成地圖的海盜潛艇**：目前照一般流程落在地圖上，不扣世界層的船殼耐久。
- **贖回俘虜**：被突擊艇帶走後只進原版的綁架追蹤，沒有專屬任務。
- **突擊艇的航程與耗能**：固定 8 格海路，不吃燃料、不吃電。

### 潛艇與進水
- **航行中破口的「整艙失蹤」**（§2.1）：艙外的人落海已做，破口艙室裡的人還沒有。
- **失蹤殖民者的打撈**（§2.4）：打撈／救援事件找回。
- **航程估算**計入推進器以外的用電與船上發電機。

### 壓力（§4.2a）
- 加壓機沒有「自動一級一級調整」的模式。
- 沒適應的醫生不徵召就進不了加壓艙照顧病人。
- 沒有耐壓到海床的門（3 級艙與深海出艙需要）。
- 艙壓高於外海時不會擋住進水。

### 海面地圖（§4.4b）
- 正式的前往方式（目前只有除錯動作「Create sea-surface map」）。
- 舊存檔的單層海面地圖不轉換。
- 平台層的快照不畫 Pawn；水面層的柱身擋住後面的東西時沒有淡出。
- 支柱腳只能從旁邊的浮船走過去（新地圖上要先有船）。

### 破冰出水（[潛艇破冰出水_機制設計.md](潛艇破冰出水_機制設計.md)）
- 冰面地圖沒有冰間水道、壓力脊、楔形碎塊；裂紋地形沒有出現時間。
- 部分開裂與頂不動沒有演出，只有信件。
- 頂冰的巨響不會讓主動聲納開一天（§8 的互動）。

### 水體視覺（[水體視覺.md](水體視覺.md) §7）
- 局部效果（熱液泉的熱擾動、可燃冰）：等內容做出來。
- 艙室層的生物光與霧氣。

### M8 終局（整段未開始）
- 深處信號、沉睡星艦、下錨修復與啟動期間的連續襲擊（§7）。

### 雜項
- 深海科研點數（目前都用一般研究點數）。
- 海洋生物：候選見 [海洋生物候選清單.md](海洋生物候選清單.md)。

## 4. 已知限制與待調整

| 項目 | 說明 |
|---|---|
| 跳幫襲擊裡的動物與機械族 | 敵方戰鬥群會帶動物或 DMS 機械族上艇；機械族不發潛水服，動物在水中會溺水 |
| 突擊艇預警時間 | 主動聲納的預警窗口約 2900 tick（48 遊戲分鐘），由 `distanceLevel` 0.4 調出，要實際玩過再定 |
| 艙內戰鬥打傷牆 | 襲擊者在艙裡開火會打傷牆、照常滲水，這是預期行為，平衡要再看 |
| 海盜潛艇數值 | 船殼 400、高爆魚雷 110（4 發沉）、4 枚攔截彈每天補 2、每 1～3 天發射 1～2 枚、船員點數至少 500，都是初值 |
| 聲納分類距離 | 偵測半徑的一半；主動聲納 7.5 格，所以 3.75 格內才分得出來 |
| 跳幫襲擊頻率 | 第 10 天起，每張開著主動聲納的海洋地圖平均 12 天一次 |
| 原版的開局威脅保護 | 新流浪者之後 300000 tick 內擋掉所有 ThreatBig（開局 3.3 天），驗收測試要用 `CanFireNowSub` 加 forced |
| 雙色衣物 | 衣物在水中會失去第二色（§2.2） |
| 驗收的屋頂坍塌信件 | 早期驗收截圖常出現「屋頂坍塌」信件，最近幾次沒有，但沒有針對性的自動檢查 |
