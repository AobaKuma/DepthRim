## 2. 光照與混濁度

- 著色器的光照 = max(g, a × `_SkyLight`)。日光**不烘進頂點**：`WaterTierMaterials.UpdateSkyLight` 每幀把「原版 `CurSkyGlow` × 層級 `ambientReach`」設給材質。烘進頂點時，白天和晚上重建的區塊亮度不同，會出現 17×17 的明暗塊。
- 人造光用 `GlowGrid.VisualGlowAt` 的原始平滑值，**刻意不套**原版給遊戲判定用的「×3.6、上限 0.5」，否則燈光變成硬邊圓盤。公式本體在 `FloodingMath.CombineLight`，取值包裝在 `WaterLight`。
- 混濁度：光照 ≥ 0.6 用 `clearAlpha`、≤ 0.05 用 `murkAlpha`，中間平滑。迷霧區固定 `_FogAlpha`。
- 艙室層另有 `_MinAlpha`（0.6 × 水位曲線）：明亮艙室裡半淹的水也看得出來；半淹時靠牆一圈泡沫；北牆正面畫水帶（高度 0.45 × 水位，`BuildingOnTop` 高度）；水位 ≥ 建築 `fillPercent` 時在建築上再蓋一層水；水面往四周實心格延伸半格，補牆貼圖兩側的透明邊。
- **潛水服頭燈**（`CompSuitLamp`）：`GlowGrid.RegisterCustomGlower`，半徑 4.5、冷白光；水位遲滯 0.06／0.02；追蹤清單在 `MapComponent_Flooding`，地圖卸載時清掉。原版第一個 handle 是 0，不能拿 0 當哨兵。
- **暗處提示：** 己方 Pawn 在混濁度 ≥ 0.5 的水裡畫淡青色輪廓，`alpha = (混濁度 − 0.5) / 0.5 × 0.6`；敵人與野生生物沒有。照明只影響畫面，不影響遊戲機制。

## 3. 水深層級（`WaterVisualTierDef`，`1.7/Defs/Rendering/WaterVisualTiers.xml`）

層級由 `IDepthTierProvider`（潛艇）或地圖的生態區決定；除錯動作「Override water visual tier」只改渲染，水壓與滲水照實際層級。外海層與艙室層各四份材質（`new Material(shader)`：`MaterialPool` 無法為同一著色器準備多份參數，`MaterialAllocator` 是 internal），層級改變時整張重建。

| 欄位 | 淺海 | 變溫層 | 深海 | 海床 |
|---|---|---|---|---|
| clearAlpha / murkAlpha | 0.40 / 0.85 | 0.45 / 0.88 | 0.50 / 0.92 | 0.50 / 0.93 |
| ambientReach（日光穿透） | 1.0 | 0.55 | 0.25 | 0.12 |
| rippleStrength / causticStrength | 0.8 / 0.30 | 0.25 / 0.08 | 0 | 0 |
| lightShaftStrength | 0.15 | 0 | 0 | 0 |
| snowDensity | 0 | 0.2 | 0.6 | 0.4 |
| biolumDensity | 0 | 0.05 | 0.25 | 0.35 |
| hazeStrength / wobbleStrength | 0 / 0 | 0 / 0.6 | 0 / 0 | 0.5 / 0 |

- 數值是 Def，調整不必重編譯。`clearAlpha` 低於約 0.35 會像「暗色玻璃」，高於 0.45 太不透明（使用者已定案）。
- 波紋尺度 0.03（約 33 格一個週期），兩層一致。
- 海洋雪：兩層視差（1.0× 與 0.42×），每顆的擺幅、頻率、相位、大小、亮度來自自己的 hash，基礎速度 0.085 格／秒，`snowSpeed` 是倍率。
- 艙室層只吃水色、混濁度、波紋；`compartmentEffects` 開啟的層級（深海、海床）另有海洋雪（`compartmentSnow()`），生物光與霧氣沒有接。
- 生物光：稀疏冷色。變溫層晃動是假扭曲（uv 偏移），不擷取畫面。

## 4. 深淵地板（`DepthRim_Abyss`）

- 地形 `dontRender`、`Impassable`、開放水域（水位固定 100%）。深淵背景層畫兩層視差微粒與遠方生物光；頂點 r = 離崖壁距離（最多 4 格），崖邊看得到崖壁往下延伸；深淵吸光（環境光 0.08，燈只照亮崖邊）。
- 崖壁：海床地形 `DepthRim_Seabed_Gravel`／`_Sand` 的 `spaceEdgeGraphicData` 用 Odyssey 小行星崖壁貼圖；`Patch_SectionLayer_TerrainEdges` 把原版只給太空畫崖壁的判斷換成「太空或海洋層」。
- `GenStep_AbyssCarve.Carve` 只在深海、海床挖洞；極地冰蓋另有 1～2 個深淵坑當船塢。
- 外觀定案為「暗洞＋柔邊」：深淵內部 ≈ 周圍水面的 0.51×、崖邊 ≈ 核心的 1.85×；外海層照常蓋在深淵上，所以沒有「亮環」。

## 5. 水中聲音（`Audio/`）

- **悶音：** `SampleOneShot.TryMakeAndPlay` 的 postfix（和原版真空同一個位置、同一個 `canVacuumDampen` 旗標）加低通濾波；`Sample.get_Volume` 的 postfix 乘音量倍率（原版每幀用 `Volume` 重設音量）。持續音效每 30 幀重套。強度 = max(聲源浸水, 鏡頭中心浸水)，迷霧格當完全在水中。完全在水中 700 Hz／0.55 倍，深海與海床截止頻率再降 20%。
- **環境音：** 四個層級的 `UnderwaterPad` 用音高區分（1.0／0.92／0.8／0.68），由 `SoundParamSource_DepthTier` 切換；鏡頭在乾艙室時壓到 45%。
- **事件音：** 進水（音量音高跟著漏水階段）、破艙（只觸發一次）、船殼承壓、排水泵、潛水呼吸與低氣量。
- 素材是 OpenGameArt 的 CC0，列在 `Sounds/CREDITS.md`；`ContentSounds` 單元測試檢查每個音檔都有列。

## 6. 進水回饋與介面

- **漏水階段**（`FloodingMath.LeakStage`）：牆耐久 > 75% 滲水、50～75% 噴水、25～50% 強噴、< 25% 湧入；進水點往艙內噴水花（`DepthRim_LeakSpray`，每 30 ticks、鏡頭內最多 8 個）。
- **露天房間逐格灌水**（`FloodingMath.OpenRoomFill`）：碰到地圖邊緣時每秒 0.05 × 水壓，只有屋頂破洞時每洞每秒 0.4 格 × 水壓；灌滿才交給外海層。
- **水密門**：門任一側水深 ≥ 75% 時，乾處、沒穿可用潛水服、沒被徵召的人打不開（走原版 `PawnCanOpen`，可達性與尋路一致）。
- **讀數**：左下角水位（`Patch_MouseoverReadout`，迷霧格不顯示）；右側天氣「海底」（`DepthRim_Undersea`）。
- **玩家設定**（`DepthRimModSettings`）：懸浮物、提示開關與強度、混濁度倍率、日光穿透倍率、頭燈半徑、悶音強度、潛水呼吸、船殼承壓聲頻率、鏡頭隨海浪擺動。

## 8. 踩過的坑

- 著色器的 `@default` **不會**自動套到材質上（`GetFloat` 回 0），新參數一律在 `WaterTierMaterials` 建材質時設定；`ContentShaders` 仍檢查每個 uniform 有 `@default`。
- `SectionLayer.ClearSubMeshes` 不移除 submesh：換過層級的區塊會留下空的舊 submesh。測試讀材質要用「第一個有頂點的 submesh」（`Tests_Visual.LiveMesh`）。
- 原版光照的實際有效半徑比 `glowRadius` 少一格（中心格的距離就是 1）：立燈 12 格約 10 格看得到。
- `DefInjected` 資料夾要寫完整型別名（`DepthRim.WaterVisualTierDef`），原版只自動補原版的命名空間。
- `ScreenCapture.CaptureScreenshot` 會延後寫檔：驗收截圖後 3 幀不推進、測試結束前多留 20 幀；截圖主題要挑已探索的格子。
- 驗收的 `run.ps1` 複製玩家 Config 時要刪掉 DepthRim 的設定檔，否則玩家調過的數值會讓視覺測試失敗。
- FPS 量測（V7）在 Ultrafast＋無 vsync 下有 ±20% 雜訊，單次數字只能參考。
