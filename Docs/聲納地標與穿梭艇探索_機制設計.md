# 聲納地標與穿梭艇探索：機制設計（2026-11-17 草案，2026-11-18 第一版實作）

> 狀態：第一版已實作（§9）：3 個遭遇型地標加 1 個地點型（沉船）。§4.4、§5 的其餘範例是之後的候選。關聯：設計稿 §3[8]「聲納探測 → 遺跡」、§4.6、§11 M4／M6。

## 1. 目標

聲納掃到的海洋地標分成兩種處理方式：

- **遭遇型（不生成地圖）**：穿梭艇開到地標時跳出對話視窗，玩家選擇怎麼處理。成敗與收益看艇上乘員的對應技能。處理完，艇載著收穫自動開回出發地。
- **地點型（生成水下地圖）**：抵達時生成一張小型海洋地圖（沉船、海底洞穴、古代設施……），乘員下艇實地探索。

兩種地標都只能靠聲納發現，延續設計稿「要不要開主動聲納本身就是風險換收益」的取捨。

## 3. 發現：聲納範圍

（已決定）主動和被動聲納都能找到所有種類的地標，差別只在範圍：主動聲納 6 格（反隱身後 7.5 格），但會暴露位置；被動聲納 3 格，不會暴露。範圍直接讀 DMSE node 的 `DetectionRange`，溫躍層遮蔽照舊生效。

- 每張開著聲納的玩家地圖（或航行中的潛艇），每天對範圍內的海洋格擲骰生成地標。上限：範圍內同時最多 N 個，全世界最多 M 個。
- 生成時依格子的生態區與水深層級挑地標（`allowedBiomes`、`depthTiers`），熱液噴口區比較常出熱液礦床，深海比較常出古代結構。
- 地標存在期限 `lifetimeDays`。會漂流的（漂流貨櫃、信標）每天漂一格，比照魚群。
- 沒分類前，世界地圖上只標「未知聲納接觸」；分類後才顯示名稱和需求技能。

## 4. 遭遇型：對話與技能判定

### 4.1 流程

```
穿梭艇抵達地標格
  → 開對話視窗（原版 Dialog_NodeTree）：描述 + 2～4 個選項
      每個選項：需要的技能、難度、乘員裡最適合的人、預估成功率
  → 選一個 → 擲骰 → 結果節點（文字 + 收益或損失）
  → 有些結果會接下一段對話（最多 2～3 層）
  → 結束：艇自動開回出發地；地標消失或標記成已探索
```

- （已決定）抵達時**暫停遊戲並立刻跳出對話**，比照商隊遭遇。對話不能用 Esc 關掉，一定要選一項。
- 「離開」一定是選項之一（不擲骰，直接回程）。
- 兩種到達方式：
  - **穿梭艇**：沿用月池的玩家突擊艇（航程 8 格），乘員是艇上的人。處理完自動開回出發地。
  - **潛艇本身**：潛艇停在地標格（不在航行中）時，世界物件多一個「調查地標」指令，乘員是船上所有人。收益直接放進船上地圖（放在艦橋旁邊）。

### 4.2 技能判定（純函式，放 `LandmarkMath`，可單元測試）

- 每個選項宣告 `skill`、`difficulty`（0～20），可選 `secondarySkill`。
- 擔任主角的乘員：自動挑艇上該技能最高、而且沒有無法執行該工作類型的人（例如「不做採礦」的人不能擔任採礦判定）。
- 成功率：`chance = clamp(base + (skill - difficulty) × 0.06, 0.05, 0.95)`，有副技能時加上 `副技能 × 0.02`。乘員受傷或缺氧時，乘上該乘員的工作能力（`Consciousness`、`Manipulation`）。
- 結果三段：**大成功**（擲骰結果低於 chance × 0.25）／**成功**／**失敗**。失敗可能受傷、消耗物品、地標失去部分收益，嚴重失敗可能讓艇損傷。
- 不論成敗，主角都得到該技能的經驗值（失敗得的較少）。

### 4.3 收益種類

| 收益 | 實作 |
|---|---|
| 物品（鋼、零件、太空材料、武器……） | 直接放進艇上的容器，回程帶回 |
| 海底研究點數 | `KnowledgeUtility.AddKnowledge`（例如古代聲學陣列） |
| 情報 | 揭露附近其他地標，或標出海盜潛艇和基地的位置（接 M7.5） |
| 人 | 救起求救信標旁的倖存者（可能招募，也可能是陷阱） |
| 升級成地點型 | 「標記座標，之後派完整隊伍過來」→ 地標轉成地點型（§5） |

### 4.4 範例地標（遭遇型）

| 地標 | 選項（技能／難度） | 收益與風險 |
|---|---|---|
| 沉沒的補給艙 | 撬開艙門（建造 6）／破解電子鎖（智力 8） | 物資；撬開失敗會讓艙體進水，損失一半物資 |
| 鯨落 | 採集骨骼（採礦 4）／採樣生態群落（醫療 6，給研究點數） | 骨頭與研究點數；腐食生物可能咬傷 |
| 求救信標 | 接近交涉（社交 8）／遠距掃描（智力 6） | 倖存者入隊；也可能是海盜誘餌，觸發突擊艇襲擊 |
| 熱液礦床 | 開採（採礦 10）／小心取樣（智力 6，給研究點數） | 礦石；高溫燙傷 |
| 古代聲學陣列 | 讀取資料（智力 12）／拆零件（建造 8） | 大量研究點數，或者先進零件；失敗會發出強信號（等同主動聲納開 1 天） |
| 漂流貨櫃 | 拖回（建造 4）／就地拆開（採礦 6） | 隨機物資；會漂流 |

## 5. 地點型：水下地圖

- 抵達時用現有的 `Arrive()` 分支生成地圖。地標的 `WorldObjectDef` 指定 `mapGenerator`：`DepthRim_Ocean` 加上專屬的 GenStep，或者 FFF 結構。
- 地圖尺寸建議用 100×100（比照海盜潛艇用自己的 `mapSize`），減少生成成本。
- 地圖跟著水深層級：水壓、能見度、進水全部照原有系統，乘員必須穿潛水服（出航前檢查要擋）。
- 回程：乘員回艇後按「出發」，目的地預設為出發地。艇上沒人、地圖上也沒有玩家建築時，地圖照 `WorldObject_OceanSite` 原本的規則移除。
- 敵方：有些地點自帶守衛（海盜補給站），或在探索中觸發深海生物。

| 地點 | 內容 |
|---|---|
| 沉船 | 進水的船體結構、需要破門的艙室、貨艙戰利品 |
| 海底洞穴 | 礦脈、可燃冰、黑暗；可能有巨物 |
| 古代海底設施（只在深海） | 古代機械、密閉艙室（有空氣）、高價值戰利品；接到終局星艦的線索 |
| 海盜補給站（聲納攔截到通訊） | 守衛戰、補給、魚雷；也就是 M7.5 海盜基地的前身 |

## 6. 資料結構（已實作）

定義檔 `1.7/Defs/Landmark/Ocean_Landmarks.xml`，程式在 `.source/DepthRim/Landmark/`。

```xml
<DepthRim.OceanLandmarkDef>
  <defName>DR_Landmark_SupplyPod</defName>
  <label>sunken supply pod</label>
  <description>（對話開場白）</description>
  <kind>Encounter</kind>                      <!-- Encounter / Site -->
  <worldObjectDef>DR_Landmark_Encounter</worldObjectDef>
  <depthTiers><li>Shallow</li><li>Thermocline</li></depthTiers>
  <commonality>1.2</commonality>
  <lifetimeDays>8~15</lifetimeDays>
  <requiredResearch>（選填）</requiredResearch>
  <options>
    <li>
      <label>Pry the hatch open</label>
      <skill>Construction</skill>
      <difficulty>6</difficulty>
      <baseChance>0.5</baseChance>            <!-- 預設 0.5 -->
      <xp>600</xp>                            <!-- 預設 600，失敗拿一半 -->
      <criticalText>… {PAWN_nameDef} …</criticalText>
      <successText>…</successText>
      <failureText>…</failureText>
      <critical>…</critical>                  <!-- 沒寫就用 success -->
      <success>
        <li Class="DepthRim.LandmarkOutcome_Things"><things><Steel>40~70</Steel></things></li>
      </success>
      <failure>
        <li Class="DepthRim.LandmarkOutcome_Injury"><damage>Cut</damage><amount>4~9</amount></li>
      </failure>
    </li>
  </options>
  <siteMapSize>(100,1,100)</siteMapSize>      <!-- 地點型用 -->
</DepthRim.OceanLandmarkDef>
```

| 類別 | 用途 |
|---|---|
| `OceanLandmarkDef`、`LandmarkOption` | 地標與選項定義；文字（含選項）走 DefInjected：`DR_X.options.0.label` |
| `LandmarkMath` | 純規則：成功率、擲骰分段、經驗值、發現機率與上限 |
| `LandmarkOutcome_Things`／`_Knowledge`／`_Injury`／`_Survivor`／`_Incident` | 結果：物品進艇、海底研究點數（乘難度研究速度）、主角受傷、倖存者加入、在乘員的家排一個事件（先檢查 `CanFireNow`，發不出來就不顯示） |
| `WorldObject_OceanLandmark` | 遭遇型（不是 MapParent）；到期消失，但有突擊艇正開過去時不會 |
| `WorldObject_LandmarkSite` | 地點型（`WorldObject_OceanSite` 子類別）；生成地圖後標成已造訪，地圖移除時地標一起移除 |
| `WorldComponent_OceanLandmarks` | 聲納發現：每小時對每個玩家 BVR 節點擲骰（`range × 0.08 / 24`）；範圍內最多 3 個、全世界最多 12 個 |
| `LandmarkEncounter` | 挑主角、擲骰、套結果、開對話；潛艇的「調查地標」指令 |
| `GenStep_Shipwreck` | 沉船：鋼牆船殼（12% 破口、船尾一定有開口）、3～4 個艙、殘缺屋頂、每艙戰利品、四周鋼渣 |

對話用原版 `DiaNode`／`DiaOption`／`Dialog_NodeTree`（不能用 Esc 或點外面關掉）。不引入「对话框架」模組：它只支援 1.4／1.5，而且綁定陣營交涉者。

## 9. 第一版實作（2026-11-18）

| 地標 | 種類 | 水深 | 選項 |
|---|---|---|---|
| 沉沒的補給艙 | 遭遇 | 淺海、變溫層、海床 | 撬開艙門（建造 6）／破解電子鎖（智力 8） |
| 求救信標 | 遭遇 | 全部 | 對接交涉（社交 8，失敗引來跳幫襲擊）／先掃描（智力 6） |
| 古代聲學陣列 | 遭遇 | 變溫層、深海、海床 | 下載紀錄（智力 12，海底研究點數；失敗引來跳幫襲擊）／拆零件（建造 8） |
| 沉船 | 地點 | 淺海、變溫層、海床 | 100×100 地圖 |

- **突擊艇**：目的地可以是遭遇型地標（不檢查潛水裝備，因為不下艇）；選目的地時游標旁顯示地標名稱。航跡記住出發地（`home`），處理完開回去，出發地是移動中的潛艇時追著它；回到海面地圖時降在那張地圖上，不另開海洋地點。
- **潛艇**：停著（不在航行中）且同一格或相鄰格有遭遇型地標時，多一個「調查地標」指令。乘員 = 船上地圖的所有殖民者，收穫放在艦橋旁。
- **對話被關掉**（讀檔、其他模組關視窗）：對話會暫停遊戲，所以遊戲還在跑、對話卻沒結束時，突擊艇會重新打開對話。
- **除錯動作**：「Spawn sonar landmark nearby」在目前地圖海路 4 格內放指定的地標。
