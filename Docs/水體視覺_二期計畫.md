### 0.3 新發現的問題

1. **`WaterVisualTierDef` 的翻譯資料夾名稱錯誤，四個層級的繁中名稱不會被載入。**
   - 原版 `LoadedLanguage` 用資料夾名稱呼叫 `GenTypes.GetTypeInAnyAssembly(name)` 來找 Def 型別。這個查詢只會自動補上原版的命名空間（Verse、RimWorld 等），**不會**找到 `DepthRim` 命名空間裡的型別。
   - 目前資料夾叫 `DefInjected/WaterVisualTierDef/`，查不到型別，會被當成載入錯誤跳過（併入「Traditional Chinese has N errors」的計數，不會單獨印出）。
   - 正確名稱是 **`DefInjected/DepthRim.WaterVisualTierDef/`**。DMSE（`DMSE.MissileBodyDef`）和其他模組（`WalkerGear.SlotDef`、`Fortified.AirSupportDef`）都是這樣命名。
   - 單元測試 `ContentDefInjected` 只檢查「鍵對應的 Def 與欄位存在」，沒有檢查資料夾名稱能不能被原版解析，所以沒有抓到。**應補一項檢查：** 資料夾名稱經過「原版的命名空間補全規則」後必須對應到 Def 型別；非原版命名空間的型別必須寫完整名稱。
2. **深淵地形沒有繁中翻譯。** `DepthRim_Abyss`（label `abyss`）是 P2-10 新增的 `TerrainDef`，`DefInjected` 底下沒有 `TerrainDef` 資料夾。
3. **繁中翻譯錯誤總數 559。** 這是整個遊戲（原版加上所有模組）的數字，不全是 DepthRim 的。要確認 DepthRim 佔多少，需要在遊戲裡產生翻譯報告；目前沒有做。
4. **文件開頭的狀態句過時**：仍寫「二期尚未開始」，已在上方加註。

### 1.4 待改進的地方

依嚴重程度排列。

**必須處理**

1. ~~**截圖不可靠。**~~ **已解決（§1.5）。** 根因是 Unity 的 `ScreenCapture.CaptureScreenshot` 會延後寫檔，而測試在截圖後立刻換相機或結束測試（`EndTest` → `CleanupAfterTest` 會把當前地圖切回地表）。現在：截圖後 3 幀內測試幫浦不推進、測試結束前再多留 20 幀才結算，並且 V7 只拍已探索的格子。
2. ~~**修正 V6 的抽樣計數錯誤**~~ **已解決（§1.3）**，現在 40／40。
3. **屋頂坍塌通知持續出現。** 每次驗收截圖右側都有十多個「屋頂坍塌」信件，也出現過「有殖民者需要救援」。測試清理會拿掉自己蓋的屋頂，但仍有坍塌發生，來源還沒查清楚。這會汙染截圖，也代表測試之間有殘留。**（最新幾次執行的截圖已不再出現坍塌信件，但沒有針對性檢查，仍列為未結案。）**

**應該處理**

4. **繁體中文缺少 DefInjected 翻譯。** 26 個 Def 標籤（冰洋圖層、生態區、升降井、排水泵、潛水服、水壓抗性、各 hediff、四個水體層級）只有英文。Keyed 翻譯兩種語言齊全，但 Def 的 label、description 沒有。
5. **頭燈的追蹤清單是全域靜態的。** `SuitLampUpdater.tracked` 跨所有地圖共用，`Reset()` 定義了但沒有任何地方呼叫；地圖卸載後，那張地圖上的潛水服 Comp 會一直留在清單裡（直到物品被銷毀）。多張水下地圖同時存在時，也會互相觸發不必要的 `UpdateLamp`。
6. **`WaterTierMaterials.Reset()` 只放掉參考、不銷毀材質。** 除錯動作反覆重建會累積材質。頻率很低，但應該補上 `Object.Destroy`。
7. **己方提示的朝向。** `MapComponent_DarkWaterHints` 只區分 West 與其他方向（北、南都用東向材質）。需要確認剪影圖形在北、南方向是否正確。

**可以之後處理**

8. **艙室層效果（D3）：** `compartmentEffects` 只是欄位。
9. **FPS 量測雜訊（D5）：** Ultrafast＋無 vsync 下 ±20%，90% 門檻只能當參考。
10. **頭燈只在水位 > 0.05 時亮（D6）：** 乾的艙室裡穿潛水服不亮燈。這符合設計，但半淹艙室的「水位 0.04」邊界值可能讓燈閃爍，需要加遲滯。

- 驗收 20／20、單元測試 795／0、著色器編譯錯誤 0。

### 2.7 P2-10 深淵地板（虛空地板）

#### 2.7.1 目的

做一種類似 Odyssey 太空地圖「虛空」的地板 `DepthRim_Abyss`：地板層本身不畫，在原本該是地面的地方露出地板之下的部分，呈現深淵般的虛無黑暗。

**用在哪裡：**

| 場景 | 用法 |
|---|---|
| 潛艇航行中的船體地圖 | 當作 DMSE 轉移飛行的 `voidTerrain`：船殼外面就是深淵。這正好符合設計稿「航行中艙外不渲染」，也解決目前 DMSE 船體地圖鋪的是太空 `Space` 地形的問題。 |
| 深海、海床地圖 | 海溝、斷崖、無底的裂谷：地圖上的一部分是深不見底的深淵，邊緣有崖壁。 |
| 冰洋基地（淺海） | 暫時不用。淺海看得到海床，沒有深淵。 |

#### 2.7.2 原版的做法（已查證）

- Odyssey 的 `Space` 地形設了 `dontRender = true`：`SectionLayer_Terrain` 在這種格子上不畫地形貼圖，只畫一個陰影遮罩（`MatBases.ShadowMask`）。
- 太空地圖的地圖生成器設了 `renderWorld = true`，所以沒畫地形的地方會透出後面的行星與星空。
- `SectionLayer_TerrainEdges` 會在「實心地形」與「`dontRender` 格」的交界畫崖壁邊緣，前提是實心地形有 `spaceEdgeGraphicData`。原版岩石地形（`TerrainDefGenerator_Stone`）會自動產生這組資料，用的是 Odyssey 小行星的崖壁貼圖。
- DMSE 的 `Patch_OrbitalPlatform.xml` 為虛空格補了 `VoidSpace` 承載力，讓軌道平台能蓋在虛空上。

DepthRim 沿用前兩點的機制，但**不能**用 `renderWorld`（水下不該透出行星），所以要自己畫深淵背景。

#### 2.7.3 設計

**1. 地形 `DepthRim_Abyss`**

| 欄位 | 值 | 理由 |
|---|---|---|
| `dontRender` | true | 原版不畫地形，崖壁邊緣也會自動判定 |
| `passability` | Impassable | 和 `Space` 一樣不能走；航行中本來就不能出艙 |
| `affordances` | `Bridgeable`、DepthRim 自訂的 `DepthRim_AbyssAnchor` | 可以在上面蓋船塢平台或錨定結構（比照 DMSE 的 `VoidSpace`） |
| `natural` | true | |
| `holdSnowOrSand` | false | |
| `avoidWander` | true | |
| `exposesToVacuum` | false | 和太空不同：這裡是水，不是真空 |
| `tags` | `DepthRim_Abyss` | 給程式判斷用，不用 defName 比對 |

**2. 深淵背景層 `SectionLayer_AbyssBackdrop`**

- 只在 `DepthRim_Abyss` 格輸出四邊形，畫在 `AltitudeLayer.BelowTerrain`（地板層之下）。
- 新著色器 `DepthRim_Abyss.frag.glsl`：
  - 底色是接近純黑的深藍，越靠近深淵中央越黑。
  - **視差深度感：** 兩、三層緩慢下沉的微小顆粒，每層的移動速度、大小、亮度都不同，越「深」的層越小、越慢、越暗，看起來像往下望進無底的深處。
  - 零星、很暗的遠方生物光，比水中的生物光更模糊。
  - 鏡頭拉遠時降低顆粒亮度，避免變成雜訊（沿用 `_CameraZoom`）。
- **頂點色：** r = 離崖壁的距離（0 = 緊鄰實心地形，1 = 深處，最多算 4 格），讓崖壁下方有一圈「看得到一點崖壁往下延伸」的過渡，再往內才是全黑。
- **光照：** 深淵吸光。燈光只照亮崖壁附近的一小段，不會讓深淵中央變亮（著色器裡把光照值乘上離崖壁距離的反向）。

**3. 崖壁邊緣**

- 原版 `SectionLayer_TerrainEdges` 只要相鄰地形有 `spaceEdgeGraphicData` 就會畫崖壁。

### 2.8 P2-11 水中聲音

#### 2.8.1 目的

讓「在水裡」聽起來和「在乾的艙室裡」不同：

- 水中的聲音悶、遠、低頻。
- 艙室裡是相對清楚的人造環境，伴隨船殼的嗡鳴。
- 越深越安靜、越壓迫，偶爾傳來船殼承壓的吱嘎聲。

做法參考 Odyssey 的真空音效。

#### 2.8.2 原版的做法（已查證）

**1. 真空中的定位音效**（`Verse.Sound.SampleOneShot.TryMakeAndPlay`）

- 只處理「有位置」的單次音效（`onCamera = false`），並且 `SubSoundDef.canVacuumDampen` 要為 true（預設 true）。
- 地圖的生態區 `inVacuum` 時，讀取發聲格子的真空程度 `v`（0–1），再套一次 `EaseOutCubic`：
  - **音量** × `Lerp(1, 0.05, v)`：完全真空時只剩 5%。
  - **低通濾波**（`SoundFilterLowPass`，Q = 0）的截止頻率依曲線變化：`v = 0 → 22000 Hz`、`0.25 → 4000 Hz`、`1 → 400 Hz`。
- **持續音效（`SampleSustainer`）沒有真空處理**，只套 SoundDef 自己的濾波器。

**2. 環境音**

- 由生態區的 `soundsAmbient` 播放（太空地圖用 `Ambient_SpaceMap`）。
- 音量透過參數對應調整，例如 `SoundParamSource_CameraAltitude`（鏡頭高度）、`SoundParamSource_AmbientVolume`（玩家設定）、`SoundParamSource_Underground`（地下地圖靜音）。

**3. 可用的工具**

- 濾波器：`SoundFilterLowPass`、`SoundFilterHighPass`、`SoundFilterReverb`、`SoundFilterEcho`。它們在音源上建立對應的元件（`GetOrMakeFilterOn<T>`），1.7 的音訊系統也支援（真空效果就是用這個）。
- 參數來源：可以自訂 `SoundParamSource` 的子類，在 SoundDef 的 `paramMappings` 裡使用。

#### 2.8.3 設計

**1. 水中悶音（比照真空，套在單次音效）**

- Harmony postfix `SampleOneShot.TryMakeAndPlay`：
  - 條件：水下地圖、有位置的音效、`canVacuumDampen` 為 true（沿用原版的旗標，不另外加）。
  - 讀發聲格的「浸水程度」`w`：開放水域 = 1；密閉艙室 = 艙室水位；迷霧格 = 1（不洩漏地形）。
- **聽者也要考慮**：鏡頭中心所在格的浸水程度 `l`。實際悶音強度 `m = max(w, l)`：
  - 鏡頭看著乾的艙室，艙室外的聲音仍是悶的（聲源在水中）。
  - 鏡頭看著水中，所有聲音都是悶的（「聽者」在水中）。
  - 只有聲源和鏡頭都在乾的艙室時才是清楚的聲音。
- 曲線（初始值）：

| m | 截止頻率 | 音量倍率 | 說明 |
|---|---|---|---|
| 0 | 22000 Hz | 1.0 | 乾的艙室，不處理 |
| 0.25 | 3000 Hz | 0.85 | 半淹的艙室 |
| 1 | 700 Hz | 0.55 | 完全在水中 |

  - 和真空不同：水會傳聲，所以音量不像真空那樣掉到 5%，只是變悶、變小聲。
  - 截止頻率比真空高一些（700 vs 400 Hz），讓水中的槍聲、機械聲仍聽得出是什麼。
- 依水深層級再微調：深海、海床的截止頻率再降 20%，聲音更沉。

**2. 持續音效（原版真空沒有處理的部分）**

- 排水泵、反應爐這類機械的持續音效也要變悶，而且會隨時間改變（艙室抽乾後聲音變清楚）。
- 做法：`MapComponent_UnderwaterAudio` 每 30 幀掃描一次目前地圖的持續音效（`Find.SoundRoot.sustainerManager`），對有位置的樣本重新套用相同的悶音曲線。
- 只改截止頻率與音量倍率，不重建音源；倍率記在樣本上，避免重複乘。

**3. 環境音（依層級）**

| 層級 | 環境音內容 |
|---|---|
| 淺海（冰洋基地） | 冰層的低沉碎裂與擠壓聲、遠方的水流聲、偶爾的冰層崩落 |
| 變溫層 | 起伏的低頻水流、模糊的遠方回聲 |
| 深海 | 幾乎無聲的低頻嗡鳴、極少的遠方生物鳴叫 |
| 深海海床 | 低頻嗡鳴加上沉積物的細碎聲、熱液泉附近的冒泡聲（局部，P2-7） |

- 生態區的 `soundsAmbient` 掛四條環境音，每條用自訂參數 `SoundParamSource_DepthTier` 控制音量：只有目前層級的那一條是 1，其他是 0。層級改變時交叉淡入淡出。
- 另一個自訂參數 `SoundParamSource_CameraInCompartment`：鏡頭中心在乾的艙室時，水中環境音降到 30%，改由艙室環境音補上（船殼與維生設備的嗡鳴）。
- 沿用原版的 `SoundParamSource_AmbientVolume`，玩家的環境音音量設定一樣有效。

**4. 事件音效**

| 事件 | 觸發 | 音效 |
|---|---|---|
| 船殼承壓 | 深海、海床，每隔隨機時間；有受損牆時更頻繁 | 金屬吱嘎、低沉的悶響（定位在受損牆或隨機外牆上） |
| 進水 | 艙室水位上升中（受損牆、打開的門） | 持續的水流聲，音量隨進水速度 |
| 破口 | 牆被打穿、艙室變成開放水域 | 一次大型灌水聲 |
| 排水泵 | 排水泵運作時 | 持續的抽水聲（受上面的悶音處理） |
| 潛水呼吸 | 穿潛水服、在水中的殖民者 | 週期性的呼吸與氣泡聲，只在鏡頭附近、低音量 |
| 氧氣不足 | 氧氣低於 20% | 急促的呼吸與警示音 |
| 升降井 | 進出升降井 | 機械運作與鐵籠聲 |

**5. 聲音素材**

- DepthRim 目前沒有任何音檔。
- **原型期：** 先借用原版音檔（例如 `Ambience/Amb_Space`、原版的水聲與機械聲），搭配濾波器做出水中感，確認流程可行。
- **正式版：** 使用可商用、可再散布的授權（CC0 優先，例如 freesound.org 上標為 CC0 的素材），或自行錄製、合成。每個音檔的來源與授權都要記在 `Sounds/CREDITS.md`。
- 格式：`.ogg`，放在 `Sounds/DepthRim/` 底下（`LoadFolders` 的 `/` 已涵蓋根目錄的 `Sounds/`）。
