- **出水演出（§6，`SubmarineSurfacingCutscene`）**：沿用 DMSE 離港過場的流程（擷取船體影像、暫停遊戲、照原版「重力船過場」設定可以關掉），演出結束才真正把船體搬上來。
  - 破冰（10 秒）：冰下暗影、放射裂紋照出現時間從接觸點長出並冒雪粉 → 2 s 起冰面泛白、輕震 → 3.5 s 破裂：環、碎冰、開放水一次出現，大震、巨響、上百塊碎冰四射、水花、雪霧 → 船體放大並從深藍變回原色、碎冰從船邊滑落 → 7 s 起上下輕晃、開放水冒海煙。鏡頭整段固定、一開始就取景到整片會裂開的冰（2026-11-14 減少縮放：不再隨裂紋拉遠，船體浮出只從 0.96 倍放大到 1 倍；下潛的離港過場也不再拉遠，船體只縮到 0.92 倍）。

## 0. 範圍與前提

| 項目 | 決定（草案） |
|---|---|
| 在哪裡可以破冰 | 潛艇所在的海洋格是**極地冰蓋**，而且正上方的地表格是**海冰**（原版 `SeaIce`）或**結冰區的海**（季節性海冰）。 |
| 哪裡不行 | 正上方是**冰原**（陸上的冰）：冰棚厚 100～500 m，任何潛艇都頂不開。正上方沒有冰的海走常規上浮（見上方「實作與設計稿的差異」）。 |
| 深度 | 潛艇要停在**淺海**：不在航行中、巡航深度＝目標深度＝淺海。 |
| 結果 | 地表圖層上那一格建立「破冰點」地圖，船體搬進冰面上的破口。海洋層的潛艇世界物件移除（和下錨一樣）。 |
| 回去 | 從破冰點下潛（DMSE 起飛），回到正下方的海洋格，恢復成潛艇世界物件。 |
| 和「不做水面」原則 | 原則已經因海上平台（§4.4b）放寬。破冰出水不加入水面航行：出水後只能停在原地，要移動就得先下潛。 |

**比例尺：** 冰的幾何計算需要「一格多大」。本文採 **1 格 = 2 m**（常數 `IceBreachMath.CellMeters`，可調）。這個值只影響裂紋的長度與碎冰帶的寬度，不影響成功與否。

## 1. 整體流程

```
[A] 冰下就位
      │  潛艇在極地冰蓋淺海停下（不在航行中、巡航深度 = 淺海）
      ▼
[B] 量測冰層（1 小時）
      │  破冰結構內建的上視聲納量出冰厚、冰型、有沒有冰間水道；預估成功率
      ▼
[C] 選擇破冰點
      │  生成冰面地圖（地表圖層同一個格子 ID），玩家選船體落點
      ▼
[D] 懸停上升（1 小時）
      │  慢慢上浮，讓破冰結構正上方的艙頂貼近冰底
      ▼
[E] 緊急吹除・頂冰（演出約 10 秒）
      │  計算 R = 可用上浮力 ÷ 需要的力
      ├─ R ≥ 1.00      → [F] 出水成功
      ├─ 0.75 ≤ R < 1  → 部分開裂：冰被頂裂但沒穿；1 天內再試，冰的抗彎厚度打 7 折
      └─ R < 0.75      → 頂不動：破冰結構受損
      （每次嘗試後要 6 小時重新注水、充氣才能再試）
      ▼
[F] 出水
      │  冰面破開、碎冰被推開、船體浮出；船體搬到冰面地圖
      ▼
[G] 冰面停留
      │  人員可以走上冰面；破口開始重新結冰
      ▼
[H] 下潛離開
         破口的冰不超過 0.4 m 才能下潛；太厚 → 船被凍住，要鑿冰
```

失敗不會讓潛艇損失：失敗後潛艇仍是海洋層上的世界物件，冰面地圖如果還沒放任何東西就移除。

### 2.2 破冰結構

船艙**內部**的建築：一組頂住艙頂的加強肋材與千斤頂，把冰的反作用力從艙頂傳到龍骨。它不是船殼，不朝外海，所以不影響船殼耐壓（`HullPressure.IsHullPiece` 不算它），也不會漏水。

| 項目 | 內容 |
|---|---|
| defName | `DepthRim_IceBreakerFrame` |
| 尺寸 | 3×3，只能蓋在船體平台上 |
| 放置條件 | 整個佔地都要有屋頂、在密閉艙室裡（`PlaceWorker_IceBreakerFrame`：放置時檢查屋頂；開放水域、露天甲板不行） |
| 造價 | 鋼 150、塑鋼 40 |
| 數值 | HP 1200；可破冰厚上限 **2.0 m**；不可通行（像龍骨一樣佔地） |
| 能力 | ① 有它才能用「破冰出水」（沒有時指令停用）② 「量測冰層」指令（內建上視聲納）③ 冰層開裂的起點（接觸點 = 結構的中心） |
| 多座 | 可以蓋不只一座：開裂從每一座同時開始，受損平均分攤；上浮力與需要的力不變 |
| 艙頂 | 頂冰時結構正上方 3×3 的屋頂承受衝擊，但不會坍塌（結構撐著）；結構被毀時，上面的屋頂照原版規則處理 |

## 3. 冰厚計算

### 3.1 冰型

| 正上方的地表格 | 冰型 | 冰厚 |
|---|---|---|
| 原版 `SeaIce` 生態區 | 多年冰 | 一年冰厚度 + 多年冰加成（1.0～2.0 m，依格子雜訊） |
| 結冰區的海（年均溫 < −10 °C，或最近海岸是冰原） | 一年冰（季節性） | 只有一年冰厚度；夏季可能整個化掉（h = 0 → 不屬於本機制） |
| 冰原（`IceSheet`） | 冰棚 | 不可破冰 |
| 其他 | — | 不可破冰 |

### 3.2 一年冰：冰凍度日法（Lebedev 經驗式）

海冰厚度大致和「累積冰凍度日」（FDD，freezing degree-days）的 0.58 次方成正比：

```
h_FY = 0.0133 × FDD^0.58        （m；FDD 單位 °C·日）
```

RimWorld 一年只有 60 天，直接用遊戲天數算出來的冰太薄，所以換算成**真實日當量**：

```
FDD = Σ  max(0, T_f − T_t) × 5 × (365 / 60)
      t
```

- `T_f` = −1.9 °C（`OceanTemperature` 的海水冰點）。
- `T_t` = 第 t 個十二分之一年的平均氣溫（原版 `GenTemperature.AverageTemperatureAtTileForTwelfth`）。每個十二分之一年是 5 天。
- 累加範圍：從一年中最暖的十二分之一年（冰最少的時候）的下一段開始，累加到「現在」這一段。
- **融冰**：這段期間若有高於 0 °C 的十二分之一年，扣掉 `0.005 × MDD`（m；MDD 是融化度日，同樣換算成真實日當量）。
- 結果夾在 0～3.5 m。

| FDD（°C·日） | h_FY |
|---|---|
| 500 | 0.49 m |
| 1000 | 0.73 m |
| 2000 | 1.09 m |
| 4000 | 1.63 m |
| 6000 | 2.07 m |

### 3.3 局部變化

- **格內雜訊**：最終冰厚 ×（0.8～1.2），用格子 ID 和年份當種子，同一季內穩定。
- **冰間水道（leads）**：每個格子每季有 `P_lead = 0.15 +（季節交替時 +0.25）` 的機率存在水道。量測時找得到；在水道裡破冰時冰厚改為 `max(0.1, h × 0.25)`。
- **雪**：本版不算（雪的重量相對冰很小）。

### 3.4 抗彎強度

海冰越冷越硬：

```
σ_f = 0.40 + 0.006 × max(0, −T_air)      （MPa，上限 0.75）
```

例：氣溫 −20 °C → σ_f = 0.52 MPa。

## 4. 開裂計算

### 4.1 特徵長度（冰板「彎多遠才斷」）

浮冰是彈性地基上的薄板，特徵長度決定裂紋與碎冰帶的尺度：

```
l_c = ( E × h³ / (12 × (1 − ν²) × ρ_w × g) )^(1/4)
```

| 符號 | 值 |
|---|---|
| E（海冰楊氏模量） | 5 GPa |
| ν（泊松比） | 0.33 |
| ρ_w（海水密度） | 1025 kg/m³ |
| g | 9.81 m/s² |

| h | l_c | 換成格數（÷ 2 m） |
|---|---|---|
| 0.3 m | 5.95 m | 3.0 |
| 1.2 m | 16.8 m | 8.4 |
| 2.5 m | 29.2 m | 14.6 |

### 4.2 需要的力

頂破冰面需要兩部分：

**(a) 彎斷冰板**（Kerr 點載荷穿透公式，只算第一個接觸點，其餘冰面被船體往上推的過程中接連斷開）：

```
P_break = C_b × σ_f × h_eff²          C_b = 3.0
```

- `h_eff`：用來算彎曲的厚度。冰被頂裂過（部分開裂，1 天內）時是 `h × 0.7`，否則等於 h。

**(b) 把船體正上方的冰推出水面**：

```
W_lift = k_lift × ρ_i × g × h × A_hull          k_lift = 0.3，ρ_i = 917 kg/m³
```

- `A_hull` = 船體佔地格數 × CellMeters²。`k_lift` 代表真正被抬起的比例，其他碎冰會從船身兩側滑落。
- 這一項用實際的 h，裂過的冰一樣重。

```
F_need = P_break + W_lift
```

### 4.3 可用的上浮力

緊急吹除主壓載得到的儲備浮力，和船體大小成正比：

```
F_up = 船體佔地格數 × 2.4 t × g
```

- 真實潛艇的儲備浮力約是排水量的 10～15%，2.4 t／格是照這個比例抓的。
- 上浮力和 W_lift 都隨船體面積變大，所以大船主要是在 P_break（彎斷冰板）這一項上佔便宜：船越大越好頂。
- 推進器不提供垂直推力。
- 每次嘗試後要 **6 小時**重新注水、充氣才能再試（指令顯示倒數）。

### 4.4 判定

```
R = F_up / F_need
```

| R | 結果 | 後果 |
|---|---|---|
| h > 結構上限 | 不能嘗試 | 指令停用：「冰層 ○ m，超過破冰結構的上限 ○ m」 |
| R < 0.75 | 頂不動 | 破冰結構受損；冰面不變 |
| 0.75 ≤ R < 1.0 | 部分開裂 | 破冰結構受損；放射狀裂紋出現但沒有穿透；1 天內再試 h_eff = 0.7 h |
| 1.0 ≤ R < 1.5 | 出水 | 一般破口 |
| R ≥ 1.5 | 猛烈出水 | 裂紋更長、碎冰帶更寬、演出更大；破冰結構受損不增加 |

### 4.5 破冰結構受損

```
每座破冰結構受到的傷害 = 120 × (P_break / 2 MN) × 失敗倍率 / 破冰結構數量
```

- 失敗倍率：成功 1.0、部分開裂 1.3、頂不動 1.5。
- 破冰結構血量低於一半時，可破冰厚上限減半。
- 傷害型別用鈍擊，由原版的建築傷害流程處理（會留下需要修理的損傷）。

### 4.6 計算範例

船體 24×8 = 192 格（A = 768 m²），一座破冰結構，氣溫 −20 °C，冰厚 1.2 m。

| 項目 | 第一次 | 第二次（6 小時後、1 天內） |
|---|---|---|
| σ_f | 0.52 MPa | 0.52 MPa |
| h_eff | 1.2 m | 0.84 m |
| P_break = 3 × σ_f × h_eff² | 2.25 MN | 1.10 MN |
| W_lift = 0.3 × 917 × 9.81 × 1.2 × 768 | 2.49 MN | 2.49 MN |
| F_need | 4.74 MN | 3.59 MN |
| F_up = 192 × 2.4 t × 9.81 | 4.52 MN | 4.52 MN |
| R | **0.95 → 部分開裂** | **1.26 → 出水** |
| 破冰結構傷害 | 120 × 1.12 × 1.3 = 175 | 120 × 0.55 × 1.0 = 66 |

這個例子說明了設計意圖：冰太厚時玩家有三條路——換一艘更大的船、找冰間水道、或者「先頂裂、等 6 小時再頂穿」。多蓋一座破冰結構不會讓 R 變大，只會分攤受損。

## 5. 冰層開裂的圖樣（地圖上的樣子）

純函式 `IceCrackPattern.Generate(footprint, contacts, lCells, R, seed)`，輸出每一格的狀態。相同輸入一定得到相同圖樣（可單元測試、可存檔重現）。

### 5.1 格子狀態

| 狀態 | 地形 | 可通行 | 說明 |
|---|---|---|---|
| 完整冰 | `DepthRim_SeaIceSheet` | ✅ | 浮冰。承載力依冰厚：≥ 1 m Medium、0.3～1 m Light、< 0.3 m 沒有 |
| 裂紋 | 地形不變，`MapComponent_IceSheet` 記錄裂紋寬度與方向 | ✅ | 只是畫面上的裂縫；美觀度 −1 |
| 碎冰 | `DepthRim_IceRubble` | ✅（路徑成本 +14，半身掩體） | 被推開、疊起來的冰塊 |
| 開放水 | `DepthRim_BreachWater` | ❌ | 類虛空，和海面地圖的開放海面同一套：東西掉下去會沉；Pawn 掉下去算落海 |
| 船體 | 船體平台 | — | 船體佔地 |

### 5.2 生成步驟

以**船體佔地的距離場**為基準（BFS，歐氏近似），不是單一點，因為船體是長的。

1. **開放水帶**：距船體 1 格內 → 開放水。船體四周一定有一圈水，看起來是浮在破口裡。
2. **碎冰帶**：距船體 ≤ `d_r = round(0.35 × l_c(格) × √R)`，最少 2 格 → 碎冰。邊緣用雜訊打散（±1 格），不會是工整的矩形。
3. **放射裂紋**：每個接觸點（破冰結構中心正上方）發出 `n_r = clamp(4 + round(2 × (R − 1)), 4, 8)` 條裂紋。
   - 角度平均分配再加 ±15° 抖動。
   - 長度 `L = l_c × (2.0 + 0.8 × (R − 1)) × rand(0.8, 1.2)`（格），從碎冰帶外緣起算。
   - 每走 1 格方向抖動 ±12°，每走 3 格有 15% 機率分岔（分岔長度是剩餘長度的一半，最多兩層）。
   - 部分開裂（0.75 ≤ R < 1）時只生成放射裂紋，長度 × 0.6，沒有碎冰帶、沒有開放水。
4. **環狀裂紋**：距船體 `r_c = d_r + l_c × 0.9` 附近（±0.5 格）、而且雜訊值高於 0.35 的格子 → 裂紋。只在兩條放射裂紋之間的扇區畫，所以是斷續的環。
5. **楔形碎塊**：被兩條放射裂紋與環狀裂紋圍住、距船體 < `r_c × 0.6` 的扇區，30% 機率整塊變成碎冰（冰板沿裂紋斷成楔形，被頂翻）。
6. **夾在地圖內**：落點至少要離地圖邊緣 `r_c + L_max + 3` 格；放置時不夠就不讓選（DMSE 選位降落的有效範圍要多加這個檢查）。

### 5.3 每格的「出現時間」

為了演出（§6）讓裂紋從接觸點往外跑，生成時順便算每格的出現時間：

```
t_reveal = 沿裂紋從接觸點走到這一格的距離（格） / 裂紋速度（30 格/秒，畫面速度，不是物理值）
```

碎冰帶與開放水在「破裂瞬間」（§6，3.5 秒）一起出現。

### 5.4 範例

| 冰厚 | R | l_c（格） | 碎冰帶 | 放射裂紋 | 環狀裂紋半徑 |
|---|---|---|---|---|---|
| 0.3 m（水道） | 2.0 | 3.0 | 2 格 | 6 條 × 約 8 格 | 約 5 格 |
| 1.2 m | 1.25 | 8.4 | 3 格 | 4 條 × 約 18 格 | 約 11 格 |
| 2.5 m | 1.1 | 14.6 | 5 格 | 4 條 × 約 30 格 | 約 18 格 |

## 6. 出水演出

`SubmarineSurfacingCutscene`：和離港過場（`SubmarineTakeoffCutscene`）一樣繼承 DMSE 的 `TransferTakeoffCutscene` 系統，用它擷取船體影像，但演出反過來：船體從冰下浮上來。演出由 DepthRim 自己在搬船體之前播放，結束後才真正搬上來。

鏡頭固定在落點，全長 10 秒，可以按原版的略過鍵跳過（跳過時直接套用最終狀態）。

| 時間 | 畫面 | 聲音 |
|---|---|---|
| 0～2.0 s **擠壓** | 冰面不變；接觸點冒出細小的雪粉（原版 `DustPuff`，白色）；放射裂紋開始從接觸點長出（出現時間 < 2 s 的格） | 低沉的冰層擠壓聲（淺海環境音的冰層碎裂聲加低通） |
| 2.0～3.5 s **隆起** | 船體佔地與碎冰帶上畫一層漸亮的高光＋外圈陰影，看起來冰面鼓起；鏡頭輕震（0.02）；放射裂紋長到全長 | 斷續的冰裂「啪」聲，越來越密 |
| 3.5 s **破裂** | 環狀裂紋一次出現；碎冰帶與開放水的地形套用；鏡頭大震（0.15，R ≥ 1.5 時 0.25）；碎冰飛濺（冰塊 fleck，數量 ∝ 船體周長，上限 60）；每個接觸點與船體周長每 8 格一個大水花（`PawnEmergeFromWaterLarge`，倍率 1～2.5，最多 12 個，規則同平台崩塌）；一團雪霧 | 一聲巨響（冰裂＋水爆） |
| 3.5～7.0 s **浮出** | 船體影像從 0.96 倍放大到 1 倍（實作；設計稿原為 0.85），顏色從冰下的深藍（透明度 0.3）漸變到正常；碎冰 mote 從船身邊緣往外滑落；船體邊緣滴下水流 fleck；部分甲板留下碎冰塊 | 湧水聲、碎冰落水的嘩啦聲 |
| 7.0～10.0 s **穩定** | 船體上下輕晃（阻尼正弦，振幅 0.08 格，週期 1.6 s）；開放水帶冒出海煙（冷空氣遇到比較暖的海水，白色 mote 緩緩上升） | 風聲、水拍船身聲漸弱 |

**部分開裂與頂不動**的演出只有前兩段（擠壓、隆起），在 3.5 s 時改成一聲悶響與鏡頭輕震，畫面切回海洋層。部分開裂的放射裂紋會留在冰面地圖上（如果那張地圖之後保留的話）。

**出水後留下的東西：**
- 甲板上的碎冰（新污物 `DepthRim_Filth_IceChunks`），落在船體露天格與屋頂下沒有的格子上，可以清掃，在 0 °C 以上慢慢消失。
- 開放水帶的海煙持續到結冰為止（§7.2），氣溫越低越濃。

## 7. 出水後

### 7.1 地圖與地點

- `WorldObject_IceBreachSite`（地表圖層，`MapParent`）：和海面地點一樣，有玩家建築、擋住移除的 Pawn 或玩家正在看時保留地圖。
- 地圖生成 `DepthRim_IceFloe`：
  - 整張鋪 `DepthRim_SeaIceSheet`，冰厚用 §3 的值，加大尺度雜訊（±15%）。
  - 冰間水道（如果有）：一到兩條蜿蜒的開放水帶，寬 2～5 格；水道上的薄冰用新冰。
  - 壓力脊：幾條碎冰線（多年冰才有）。
  - 天氣、溫度、季節照原版地表格。
- 船體用 DMSE 的降落流程搬進來（落點是玩家選的位置）。

### 7.2 破口重新結冰

`MapComponent_IceSheet` 每 2500 tick（1 小時）更新開放水與新冰格的冰厚：

```
h(t) = 0.0133 × FDD_since^0.58
FDD_since = 出水後累積的 max(0, T_f − T_air) × (經過的遊戲天數) × (365 / 60)
```

| 冰厚 | 格子變成 |
|---|---|
| < 0.1 m | 開放水 |
| 0.1～0.3 m | 新冰（`DepthRim_NewIce`，可通行、沒有承載力、美觀度 0） |
| ≥ 0.3 m | 完整冰 |

- 氣溫 −20 °C 時（每遊戲天約 110 FDD），開放水約 0.3 天結到 0.1 m、約 2 天到 0.3 m、約 3.2 天到 0.4 m（§7.3 的下潛門檻）。
- 裂紋在累積 FDD ≥ 50 後癒合，不再畫。
- 碎冰帶不會變回完整冰（凍成一圈冰脊），但可以清除（§7.3）。

### 7.3 被凍住與脫困

- 船體四周（距離 1 格的開放水帶）的冰厚 > **0.4 m** 時，下潛指令停用：「船體被凍在冰裡」。
- 脫困方式只有**鑿冰**：新的指派「鑿開冰面」，殖民者把完整冰、新冰或碎冰鑿成開放水（工作量依冰厚，1 m 約 1 天人工／格；用採礦技能）。只要鑿開船體四周那一圈就能下潛。
- 不需要再頂一次：下潛是往下，不用破冰。

### 7.4 船上的狀態

- **艙壓**：密閉艙室保留原有壓力（概念設計稿 §4.3 的規則）。從淺海（1 級）出水到地表（0 級）只差 1 級，不會壓力不適；打開通往冰面的門時艙壓往 0 洩。
- **進水**：出水後船體在水線以上，水位系統在破冰點地圖上停用（比照海面地圖）。
  - 密閉艙室裡已經有的水保留，要靠排水泵抽乾。
  - 有破口的艙室在 1 小時內排到 0（水從破口流回海裡）。
- **溫度**：照原版地表溫度。極地 −30 °C 以下，沒有暖氣的艙室很快結凍。

### 7.5 下潛離開

- 艦橋的「下潛」就是 DMSE 的起飛，目的地固定是正下方的海洋格（同一個格子 ID）。不經過航線規劃，也不耗電。
- 用既有的離港過場（`SubmarineTakeoffCutscene`），船體往下沉進水色裡。
- 船體離開後，船體佔地格變成開放水，照 §7.2 重新結冰。
- 回到海洋層時潛艇的巡航深度是淺海，不在航行中。
- 破冰點地圖照 §7.1 的規則決定要不要保留（地上有玩家建築就保留，例如在冰面上蓋的營地）。

## 8. 和其他系統的互動

| 系統 | 互動 |
|---|---|
| 聲納與襲擊 | 頂冰的巨響很吵：出水當下等同主動聲納開 1 天（見概念設計稿「襲擊綁定主動聲納」），之後回到原本的規則。冰下的海盜潛艇在冰面地圖上不能襲擊（他們也要破冰，本版不做）。 |
| 量測冰層 | 船上有破冰結構時，潛艇世界物件與艦橋多一個「量測冰層」指令（1 小時，潛艇要停著；不需要聲納）。結果在 12 小時內有效，顯示：冰型、冰厚、有沒有冰間水道、預估的 R 與結果。沒量就頂（「盲頂」）也可以，但視窗只顯示「冰厚未知」，判定照真實值。 |
| 壓力適應 | 見 §7.4。 |
| 世界地圖 | 出水時海洋層的潛艇圖示消失，地表圖層出現破冰點圖示；一封信「破冰出水」（附冰厚與 R）。 |
| 下錨 | 破冰出水和下錨互斥：同一個時間點潛艇只能是其中一種。 |
| 船殼耐壓 | 破冰結構在船艙內，不算船殼，不影響潛艇能下多深。 |

## 9. 延伸（本版不做）

- **冰下敵人破冰追擊**：海盜潛艇也能頂冰出水，在冰面上打登陸戰。
- **冰面營地**：在破冰點蓋營地，維持一個「冰洞港口」，讓潛艇定期進出（可以再加一種讓破口不結冰的加熱建築）。
- **加大上浮力的建築**：例如壓載水艙，讓小船也頂得開厚冰。本版刻意不做。
- **冰山／冰脊撞擊**：航行經過冰緣時的船殼損傷事件。
