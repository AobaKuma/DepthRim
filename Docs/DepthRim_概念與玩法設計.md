# DepthRim — 概念與玩法設計稿 v0.3

> 一句話：**深海才是敵人，潛艇是唯一的庇護所。**
> 不是「換皮太空」，而是一個「看不見、出不去、壓力無所不在」的生存模組。

**前置需求：** 硬相依 DMSE（未來可能統合為同一框架）。

---

## 0. 設計範圍與基調

| 原則 | 說明 |
|---|---|
| 不做水面 | 沒有水面航行、水面地圖或水面事件，所有內容都在冰層之下。 |
| 襲擊綁定主動聲納 | 水下襲擊只會發生在玩家設有**主動聲納**的地圖上。沒有主動聲納的地圖（例如早期的冰洋基地）威脅只來自環境：進水、水壓、維生。主動聲納同時也是發現值得探索的水下地點的唯一手段，所以「要不要開聲納」本身就是一個風險換收益的選擇。 |
| 生物從簡 | 就算加入水下生物，也只做少量、行為簡單的種類。 |
| 礦業豐富 | 深海的回報是資源：礦脈、熱泉等，用來支撐開採與發電。 |
| 高挑戰 | 環境本身就足以致命，玩家的每一步擴張都必須先顧好排水與維生。 |

## 1. 核心設計支柱

| 支柱 | 說明 | 與「軌道 / 太空」的差異 |
|---|---|---|
| **封閉** | 航行期間只能待在艙內（比照 DMSE 軌道船）；淺海或海床下錨時才能出艙。 | 真空是逐格擴散的失壓；深海則是依船殼受損程度與深度持續進水。 |
| **無光** | 艙外一片漆黑，航行時連艙外都不顯示；下錨後艙外才可見。 | 太空至少看得到星光和敵艦。 |
| **水壓** | 越深，船殼受損造成的進水越快；牆體完全破口時，整間艙室會瞬間淹沒。 | — |
| **聽而不見** | 戰鬥靠聲納和魚雷在地圖外進行（BVR）；等你真的看到敵人，通常已經是對方跳幫上艙了。 | — |

## 2. 船殼損傷與進水規則

### 2.1 兩種狀態

| 狀態 | 定義 | 結果 |
|---|---|---|
| **船殼受損** | 船艙牆體被打傷，但還沒完全摧毀。 | 依**受損百分比 × 當前深度層級**決定進水速度，艙室水位逐漸上升。 |
| **船殼破口** | 船艙牆體被**徹底摧毀**。 | 該艙室立即淹沒；航行中發生時，**艙內殖民者全部判定失蹤**。 |

### 2.2 水位模型
- **每間艙室（Room）一個水位值**（0–100%），不做逐格計算，以兼顧效能。
- 水位上升的艙室會讓殖民者移動變慢、溺水，也會損壞設備與物品。
- **視覺：** 依艙室水位高度裁切 Pawn 的渲染，從腳往上把被淹到的部分改成水色，讓玩家一眼看出水淹到哪裡。

#### 實作（`MapComponent_Flooding`，2026-11-01）
- **開放水域：** 碰到地圖邊緣、或有任何沒屋頂格子的房間，水位固定 100%。牆被打穿、房間連到外面，就會立刻變成開放水域。
- **密閉艙室**的水位只會因三件事改變：
  - 受損牆體滲水：受損比例 × 水壓倍率（淺海 1、變溫層 2、深海 4、海床 8）× 兩側水位差。
  - 打開的門：兩側水位往平均值流動。
  - 排水泵：每秒抽 2 格。
- **存放：** 水位存在每一格（0–255），房間水位 = 格子平均。原版每次牆體變動都會重建房間物件，用格子存就能讓新房間自然繼承水位，不需要 patch 原版房間重建。
- **對 Pawn 的影響**（每 250 ticks 結算）：
  - 涉水減速。
  - 沒入水中（站著 ≥ 75%、躺著 ≥ 30%）又沒有潛水服氧氣時會溺水，約 1 小時致死。
  - 水壓抗性不足時累積水壓傷害。
- **Pawn 水位渲染**（`PawnWaterRendering`）：在水中時，每個渲染節點的材質換成原版 CutoutComplex 著色器，配一張垂直漸層遮罩。水線以上是遮罩紅色（主色 = 原色），水線以下是綠色（第二色 = 原色 × 水色）。人形身體節點約佔全身高度 0–72%、頭部約 62–100%；躺著時水位到 30% 就整個上色。不需要自訂著色器。
  - 限制：雙色衣物在水中會失去第二色；遮罩顏色慣例（紅 = 主色）要進遊戲確認。
- **水體顯示**：分兩層，GLSL 放在 `1.7/Shaders`。1.7（Waylith）會在執行期編譯，做法比照 DMS 本體。
  - **外海層**（`SectionLayer_WaterOuter` + `DepthRim_WaterOuter.frag.glsl`）：
    - 繪製順序 3177，介於原版迷霧（3175）和光照暗化（3180）之間，關閉深度測試。開放水域裡的岩體、建築、Pawn 都會被蒙上一層水，未探索的迷霧區變成深海，燈光仍然照得到水面。
    - 涵蓋範圍是迷霧格加上已探索的開放水域和岩體。已探索的密閉艙室和它們的牆不在網格裡，所以沿格子邊界乾淨地切開，並往艙室方向淡出。網格本來就是逐格的，不需要模板遮罩。
    - 迷霧格一律只帶迷霧權重，不用房間或地形資料，避免洩漏未探索的洞穴。
  - **艙室層**（`SectionLayer_WaterVolume` + `DepthRim_WaterVolume.frag.glsl`）：
    - 只畫密閉艙室裡的積水，畫在 MoteLow 高度（建築之下）。頂點水位只平均同一間艙室的格子；碰到牆和關著的門算岸邊。
  - 每格的「開放水域」旗標由 `MapComponent_Flooding` 每次更新寫入，渲染在平行執行緒也能查。Pawn 水線只用在密閉艙室；開放水域的 Pawn 由外海層蓋住。
  - 冰洋地圖現在有迷霧（`GenStep_IceOceanFog`）：開放水域可見，岩體內部保持迷霧，升降井出口會從出口揭開。
- **光照與混濁度（2026-11-01，`水體視覺分層_實作指南.md` A/B 階段）：**
  - 每個水體頂點取周圍四格的光照平均寫進頂點色的 g 通道（迷霧格一律 0，不洩漏迷霧下的光源）。光照量 = **日光與人造光取大者**：日光取原版 `skyManager.CurSkyGlow`（無屋頂時），所以白天淺海整片都算有光、不會再有「明明有太陽卻一片不透明」的暗塊；人造光（燈、頭燈）用平滑衰減的原始值，燈下才會有一圈由亮到暗的漸層。
  - 日光會乘上層級的 `ambientReach`（淺海 1.0、變溫層 0.55、深海 0.25、海床 0.12）：日光本來就穿不深，深海在白天也不會因此變透明；人造光不折減。
  - 著色器用同一條公式算「清澈度」：光照 ≥ 0.6 視為清澈（`_ClearAlpha` 0.40–0.50，看得到海底但仍是水），≤ 0.05 視為全暗（`_MurkAlpha` 0.85–0.93，依層級，幾乎看不到海底）。所以**燈照到哪裡，水就看到哪裡**；關燈後只剩層級設定的微光。迷霧區固定 `_FogAlpha`，不受光照影響。
  - 潛水服自帶頭燈（`CompSuitLamp`，半徑 4.5、冷白光 (200,225,255)）：穿著者在水中時在腳下註冊原版自訂光源（`GlowGrid.RegisterCustomGlower`），每 15 ticks 檢查、換格才搬移，脫下／死亡／倒地 10 秒後解除。
  - 暗處的己方提示（`MapComponent_DarkWaterHints`）：己方 Pawn 站混濁的水裡（混濁度 ≥ 0.5）時，用原版剪影著色器畫一層淡青色輪廓，`alpha = (混濁度 − 0.5) / 0.5 × 0.6`。敵人、野生生物、密閉艙室裡的 Pawn 都沒有提示；跟著右下角的水體顯示開關。
- **水深層級化（2026-11-01，C/D/E 階段）：**
  - 每個層級（淺海／變溫層／深海／海床）一組參數寫在 `1.7/Defs/Rendering/WaterVisualTiers.xml`（`WaterVisualTierDef`）：水色、深處色、迷霧色、混濁度上下限、波紋尺度與強度、光紋、光柱、海洋雪、生物光、沉積霧氣、變溫層晃動。
  - 淺海：大尺度波紋與穿過冰層的光柱；變溫層：水面晃動與稀疏懸浮物；深海：日光幾乎穿不到，燈下看得到海洋雪、關燈只剩生物光；海床：貼地沉積霧氣＋生物光。
  - 海洋雪是兩層不同速度的亮點（視差），每顆自己的擺幅、頻率、相位、大小與亮度都不同，所以不會整片同步往下滑；`snowSpeed` 是倍率，改 Def 就能調快慢。
  - 外海層與艙室層各準備四個材質（`WaterTierMaterials`），地圖層級改變時整張重建。艙室層只讀水色、深處色、混濁度與波紋尺度，**不套用**海洋雪／生物光／霧氣／晃動。
  - 除錯動作「DepthRim: Override water visual tier」可以手動切換層級看畫面（只影響渲染，水壓與滲水速度仍照地圖實際層級）。
- **冰洋地圖的屋頂規則（驗收測試發現後修正）：** 開放水域沒有屋頂，只有岩體上方有岩頂。玩家要圍牆**並蓋人造屋頂**才算密閉艙室。地圖生成器不能設 `isUnderground`，否則原版會把整張地圖鋪滿厚岩頂、高度全設為岩體，玩家永遠蓋不出艙室。
- **水下基地不會消失：** `WorldObject_IceOceanSite` 在還有升降井出口或玩家建築時保留地圖。原版太空地圖父物件在沒人時會移除地圖。
- **還沒做：** 航行中破口的「整艙失蹤」判定（等潛艇原型）。

### 2.3 進水的處理
- 可以用排水泵把水抽掉，並修補受損的牆體。
- 水密艙門 / 隔艙能把進水擋在單一艙室，這是潛艇設計的核心取捨：犧牲空間換安全。

### 2.4 失蹤與救回
- 因破口而失蹤的殖民者並沒有死，之後有機會透過**打撈 / 救援事件**找回（例如在海床找到殘骸艙或逃生艙）。

## 3. 遊戲流程總覽

```
[1] 冰蓋前進基地
      │  在極地冰蓋建立地面基地
      ▼
[2] 建造升降井
      │  打通冰層，開啟「地下冰洋」地圖
      ▼
[3] 第一次下地
      │  穿戴潛水裝備的人員下去探勘
      ▼
[4] 冰洋探索
      │  尋找礦產與可用於發電的資源（熱泉等）
      ▼
[5] 升降井平台基地
      │  圍著平台建造密閉區、排水、供電
      │  排完水的區域，之後下來的人不需要再穿潛水裝備
      ▼
[6] 擴展設施
      │  排水隔艙與維生系統必須跟上擴建速度
      ▼
[7] 建造潛航器（比照重力船）
      │  在水下基地建造潛艇，探索冰洋的其他位置
      ▼
[8] 深海航行循環
      │  ├─ 在四個水深層級之間下潛 / 上浮
      │  ├─ 聲納探測 → 魚群 / 海盜潛艇 / 跳幫突擊艇 / 遺跡
      │  ├─ BVR 魚雷交戰、攔截
      │  ├─ 跳幫與反跳幫
      │  └─ 在淺海 / 海床下錨 → 出艙採礦、探索、打撈
      ▼
[9] 終局：啟動水下星艦
```

地面基地在潛艇出航後仍然是一張**獨立運作的殖民地地圖**。

## 4. 各階段細節

### 4.1 冰蓋前進基地
- 起始地形限定在冰蓋生態區：極寒、資源匱乏。
- 定位是前哨、物資中轉站和升降井基座。
- 潛艇出航後仍繼續運作，作為母港。

### 4.2 升降井與第一次下地
- 「冰層升降井」完成後，會開啟一張附屬的**地下冰洋地圖**。
- 地下冰洋預設**整張都是水**；人員必須穿潛水裝備才能活動。

#### 潛水裝備的限制
| 限制 | 說明 |
|---|---|
| **氧氣時間** | 裝備內的氧氣會隨時間消耗，用完前必須回到乾區或補充。 |
| **工作效率** | 穿著裝備時工作速度下降（越重的裝備降得越多）。 |
| **移動效率** | 穿著裝備時移動速度下降。 |
| **環境水壓抗性**（新 Stat） | 決定能在哪個水深層級活動；水壓超過抗性就會持續受傷。裝備等級越高，抗性越高，但效率懲罰也越重。 |

> 「環境水壓抗性」也可以用在敵方海盜的重型潛水服、水下生物，甚至義體 / 基因上，成為一個通用的深度門檻。

### 4.3 水下基地：排水與擴張
這是前中期的主要玩法，邏輯是「把水趕出去」：

1. 圍著升降井平台蓋出密閉的牆體與屋頂。
2. 架設排水泵與電力，把密閉區域內的水抽乾。
3. 排乾的艙室變成「乾區」，人員可以不穿潛水裝備活動。
4. 每擴建一個新區域，都要重複「密閉 → 排水 → 維生」。
5. 維生系統（氧氣、暖氣、除濕）的容量會限制基地能擴多大。

> 這套「乾區 / 濕區」的判定，之後會直接沿用到潛艇的艙室進水系統（§2），兩邊共用同一套水位模型。

### 4.4 資源
- **礦業：** 冰洋與海床都有豐富的水下礦脈與山體，是推進科技與造艦的主要來源。
- **發電：** 地下熱液泉（類似原版的蒸汽間歇泉，但在水下）。
- **特殊資源：** 可燃冰（燃料 / 化工原料）、黑曜石（火山活動帶的建材）等。
- 越深的層級，資源越稀有、越珍貴。

### 4.5 潛艇建造（比照重力船）
在水下基地的船塢建造。初步的艙段 / 設施清單：

| 類別 | 項目 | 功能 |
|---|---|---|
| 結構 | 耐壓船殼（多級） | 決定可下潛的最大水深層級，並影響受損時的進水速度 |
| 結構 | 水密艙門 / 隔艙 | 把進水限制在單一艙室 |
| 動力 | 反應爐 / 電池組 | 推進、照明、維生 |
| 維生 | 氧氣再生、除濕、暖氣、排水泵 | 艙內環境維持 |
| 航行 | 壓載水艙、推進器、艦橋 | 下潛 / 上浮 / 移動 |
| 感測 | 主動 / 被動聲納 | 世界地圖視野、預警 |
| 武裝 | 魚雷管、誘餌發射器 | BVR 攻擊、攔截 |
| 對接 | 對接艙門、月池 | 跳幫攻防、整備突擊艇 |
| 出艙 | 氣閘 / 潛水裝備櫃 | 下錨時出艙作業 |

### 4.6 航行狀態（比照 DMSE 軌道船）
- **本地地圖：** 只顯示艙內，艙外不渲染。
- **世界地圖：** 視野只有聲納範圍。
  - 主動聲納：範圍大，但會暴露自己的位置。
  - 被動聲納：範圍小，但安靜。
- **允許艙內施工：** 可以在航行中改建內部，但只要拆掉外殼牆體，就會依 §2 判定為破口。
- **禁止出艙。**

### 4.7 下錨狀態
- 只能在**淺海**或**海床觸底**時下錨。
- 下錨後艙外才會顯示，而且是一張**完整的地圖**：水下礦物與山體、地下熱液泉、可燃冰、黑曜石等。
- 人員可以穿潛水裝備出艙：採礦、探索遺跡、打撈失蹤人員、從外側修補船殼。
- 如果這張地圖上有運作中的主動聲納，就可能遭到襲擊（見 §6.3）。
- 變溫層和深海（未觸底）不能下錨。

## 5. 水深分級

不使用絕對深度數值，而是用**四個層級**套用不同機制：

| 層級 | 光照 | 水壓（進水倍率） | 可下錨 | 主要威脅 / 事件 | 船殼需求 |
|---|---|---|---|---|---|
| **淺海** | 微光 | 低 | ✅ | 海盜潛艇、魚群 | 基礎船殼 |
| **變溫層** | 幾乎無光 | 中 | ❌ | 聲納干擾（溫躍層遮蔽）、伏擊、跳幫突擊艇 | 強化船殼 |
| **深海** | 無光 | 高 | ❌ | 深海海盜、大型生物、結構疲勞 | 耐壓船殼 |
| **深海海床** | 無光（生物光） | 極高 | ✅（觸底） | 遺跡、稀有礦藏、星艦相關內容 | 頂級耐壓船殼 |

機制建議：
- **船殼等級低於層級需求：** 持續累積結構疲勞，隨機造成船殼受損。
- **變溫層聲納遮蔽：** 躲在溫躍層下面比較不容易被偵測，但自己也聽不太清楚。
- **層級決定襲擊池：** 每一層有自己的事件與襲擊清單。
- **心情：** 越深越壓抑（無光、幽閉恐懼），需要照明、娛樂、舒適度來抵銷。

## 6. 戰鬥：BVR + 跳幫

建立在 DMSE 的軌道船與 BVR 系統上（硬相依）。

**觸發條件：** 只有在設有主動聲納的地圖上才會發生水下襲擊。

### 6.1 交戰流程（航行中）
```
聲納預警 ──► 目標分類（魚群 / 海盜潛艇 / 跳幫突擊艇 / 未知）
   │
   ├─ 玩家選擇：迴避 / 靜默 / 主動攻擊
   ▼
地圖外 BVR 階段
   ├─ 發射魚雷攻擊敵艦
   ├─ 發射魚雷 / 誘餌攔截來襲的突擊艇或魚雷
   └─ 被敵方魚雷命中 → 我方某段外殼受損（進水）或破口（艙內人員失蹤）
   ▼
攔截失敗 → 敵方突擊艇抵達
   ▼
本地地圖：突擊艇穿入船艙 → 室內跳幫戰
   ▼
襲擊撤退 → 存活的敵人登上突擊艇脫離
```

### 6.2 跳幫突擊艇
- 本質是一種**特殊的運輸艙**：穿入船艙時**不會破壞密閉性**（不會造成進水）。
- 突擊艇會留在艙內；襲擊撤退時，敵人會回到艇上**載人脫離**（可能帶走俘虜或物資）。
- 摧毀停在艙內的突擊艇，就能切斷敵方退路。
- **玩家方：** 可以在**月池**建造與整備自己的突擊艇，主動跳幫敵方潛艇（掠奪、俘虜、奪船）。

### 6.3 下錨時的襲擊（淺海 / 海床）
- 突擊艇不直接穿入船艙，而是降落在海床上，放下**穿重型潛水服的海盜突擊隊員**。
- 突擊隊員從艙外推進，可能攻擊外殼（造成受損進水，甚至破口）或嘗試從氣閘 / 對接艙門突入。
- 出艙作業中的殖民者會直接暴露在交戰中，所以下錨時的出艙安排本身就有風險。
- 撤退時，突擊隊員回到海床上的突擊艇脫離。

## 7. 終局：啟動水下星艦

定位是**原版「沙隆·白石」旅程任務（Journey Offer）的水下版本**。

| 原版 | DepthRim 版 |
|---|---|
| AI 沙隆·白石主動聯繫，告知遠方有一艘可用的飛船 | 主動聲納接收到來自深處的信號，指向海床上一艘沉睡的星艦 |
| 帶著殖民者長途旅行到飛船所在地 | 駕駛潛艇一路下潛到深海海床，船殼與維生必須撐得住最深層級 |
| 在當地建立據點、啟動飛船反應爐 | 下錨觸底、出艙修復星艦，並啟動它 |
| 反應爐啟動期間持續遭受襲擊 | 啟動期間主動訊號暴露位置，遭受連續的海盜與深海生物襲擊 |
| 啟動完成後，殖民者登船離開 | 星艦啟動，殖民者登艦離開 |

具體的任務文本、修復需求與襲擊強度待設計。

## 8. 實作切入點（基於 RimWorld 1.6 / Odyssey 原版系統）

以下類別已在原版源碼中確認存在，可以作為參考或掛鉤點：

| 需求 | 原版參考 | 備註 |
|---|---|---|
| 乾區 / 濕區、艙室水位 | `Verse.VacuumComponent : MapComponent` | Odyssey 的真空系統是「室外為真空、密閉艙室保有空氣」，正好可以反過來用成「室外是水、密閉且排乾的艙室是乾區」。不過水位需要持續的進水 / 排水數值，而不是只有開或關，所以要另寫 `MapComponent_Flooding`，每間艙室存一個水位值。 |
| Pawn 水位渲染 | Pawn 渲染管線（待查） | 依所在艙室水位裁切 Pawn 下半部並改色，可能需要 Shader 或額外疊一層遮罩。 |
| 環境水壓抗性 | 自訂 `StatDef` | 由裝備 / 義體 / 基因提供，和地圖的水深層級比對。 |
| 終局任務 | 原版 Journey Offer 任務 | 以它的任務結構為範本，改寫成水下版本。 |
| 潛艇建造與船體判定 | `RimWorld.SubstructureGrid`、`RimWorld.GravshipUtility` | 「比照重力船」：參考它判定連通船體範圍的方式，改成耐壓船殼。 |
| 潛艇在世界地圖移動 | `RimWorld.Planet.Gravship : WorldObject` / DMSE 軌道船 | Odyssey 的飛船在飛行中**沒有地圖**；DepthRim 航行時要保留艙內地圖，所以以 DMSE 軌道船的航行模式為主。 |
| 海洋地圖 | Odyssey `PlanetLayerDef` | 研究 DMSE 後改為獨立的圖層（而非 `PocketMapParent`），潛艇才能在世界上航行；升降井做成 `MapPortal`。詳見 [DMSE_對接研究.md](DMSE_對接研究.md) §4。2026-11-01 起「冰洋」擴充為有七種生態區的「海洋」圖層，冰洋成為其中的極地冰蓋，見 [海洋圖層與生態區.md](海洋圖層與生態區.md)。 |
| 跳幫突擊艇 | 原版運輸艙 / 空投艙 | 改成不破壞屋頂與密閉性的穿入方式，並加上撤退時的回收邏輯。 |
| 失蹤處理 | — | 把 Pawn 移出地圖並保存在世界中（不殺死），供之後的打撈事件取回。 |

> 以上仍是概念階段的筆記，動工前需要再逐一用源碼（以及 DMSE 的實作）確認細節與 Patch 點。
