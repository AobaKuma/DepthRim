# 海洋圖層與生態區

2026-11-01 實作。原本只有一種生態區的「地下冰洋」圖層，擴充成有七種生態區的「海洋」圖層。

## 使用者定案

| 問題 | 決定 |
|---|---|
| 海洋和冰洋的關係 | **取代冰洋**：只保留一個海洋圖層，原本的冰洋變成其中的「極地冰蓋」生態區 |
| 生態區怎麼分配 | **依正上方的地表格決定**，再用雜訊打散 |
| 生態區清單 | 極地冰蓋、海床平原、淺珊瑚礁、深珊瑚礁，加上熱液噴口區、深淵海溝、海藻林 |
| 珊瑚牆貼圖 | **天然岩體**：自然生成、可以開採；採到的石塊可以切成建材 |
| ShipHull 貼圖 | 抗壓水密牆（可建造） |

**限制：** 舊世界的海洋格子在存檔時就已經生成好，所以讀檔後全部是極地冰蓋。想要其他生態區必須開新世界。

| 深淵海溝 | `DepthRim_AbyssalTrench` | 海床 | 2 | 板岩、花崗岩 | 山地 | 活動大陸邊緣外的隱沒帶海溝；大量深淵（`abyssBias` 0.15） | ❌ |
| 陸塊 | `DepthRim_Landmass` | — | — | — | 照抄地表 | 陸地正下方，沒有海洋、不能進入 | ❌ |

- 所有生態區共用抽象父類別 `DepthRim_OceanBiomeBase`：地下天氣、四個層級的環境音，而且不能走出地圖。
- 珊瑚礁只列一種岩石：原版 `RocksFromGrid` 依區塊在列出的岩石之間分配，100×100 的小地圖可能整張都抽到另一種，珊瑚就不見了。
- 生態區專屬的數值放在 `WaterMapExtension`：`depthTier`、`abyssBias`、`hydrothermalVents`、`hilliness`。
- 地圖的水深層級改由生態區決定（`FloodingUtility.DepthTierOf`）。地圖父物件實作 `IDepthTierProvider` 時（之後的潛艇）仍以父物件為準。`DepthTierUtility.MaxTierAt` 也改讀生態區，取代原本的雜訊。
- **升降井的限制**（`PlaceWorker_IceShaft`）：正下方是深海或海床生態區時不能蓋，因為目前的潛水服只撐得住水壓 1。放置時滑鼠旁會顯示「下方海洋：○○」。

## 分配規則（`OceanBiomeSelector`，純函式）

2026-11-09 改版兩次（使用者定案）：
- 第一次加上大陸棚與海岸線：陸地正下方沒有海洋。
- 第二次比照真實的海底地形分布，加上中洋脊、近海隱沒帶海溝和海山。

### 海底地形骨架（`SeafloorGeometry`，在地表格網上一次算完）

- **離岸距離**與**最近的海岸格**：從所有陸地（含冰原）多源廣度優先。
- **大陸**：陸地連通塊佔全部陸地 3% 以上（至少 400 格）才算，只有一塊陸地時它一定算。小島不算大陸。
- **中洋脊軸線**：洋盆的中線。兩個相鄰水格各自最近的大陸如果在洋盆兩側（相隔 ≥ 1.3 × 離大陸距離），它們之間就是中線，所以中洋脊會落在兩岸正中間，像大西洋中洋脊。
  - 離岸不到 7 格的海沒有中洋脊。
  - 只看大陸：小島也算的話，每座小島周圍都會圍出一圈脊，變成蜂巢狀。
- **離脊距離**：從軸線廣度優先，可以越過小島。
- **活動大陸邊緣**（隱沒帶）：每段大陸海岸依低頻雜訊決定（門檻 0.6，約四分之一），水格沿用最近海岸的結果，所以整段海岸外的海溝是連續的。小島的海岸不會是隱沒帶，否則小島四周會圍出一圈海溝。

### 生態區

1. 地表是冰原（陸上的冰）→ **極地冰蓋**（冰棚下的海，升降井從這裡下去）。其他陸地 → **陸塊**（沒有海洋）。
2. **結冰區**（海冰、年均溫低於 −10 °C 的海、最近海岸是冰原的水）：冰蓋與深洋盆的交界**犬牙交錯**（2026-11-09 使用者要求）。
   - 高頻碎形的冰緣雜訊（頻率 0.08、5 層、持續度 0.65）決定極地冰蓋從海岸往外伸幾格：`IceReach`，0 到「大陸棚 + 8」格。雜訊先在 0.25–0.75 之間拉伸對比。
   - 伸得遠的地方是**冰舌**：伸出大陸棚的部分是冰下淺灘，200–800 m。
   - 伸得近（甚至 0）的地方，原本是大陸棚／大陸坡的格子變成切進冰蓋的**洋盆海灣**，離岸距離當成大陸坡外一格，照遠洋規則，所以是深的。
   - 再往外照下面的一般規則，浮冰底下的洋盆一樣深，像真實的北冰洋。
   - 同一天稍早在 100% 覆蓋率下發現：原本整片極地海都是極地冰蓋，又被夾成 50–800 m，看起來像一大片淺棚。
3. **被動大陸邊緣**：
   - 大陸棚（離岸 1–2 格）：結冰 → 極地冰蓋；≥ 20 °C → **淺珊瑚礁**；−2 到 20 °C → **海藻林**；更冷 → 極地冰蓋
   - 大陸坡（3–4 格）→ **深珊瑚礁**
4. **活動大陸邊緣**：
   - 大陸棚只有 1 格，生態區規則同上
   - 大陸坡 2–3 格 → **深珊瑚礁**
   - 坡腳外 4–5 格 → **深淵海溝**（平行海岸）
5. **遠洋**：
   - 中洋脊軸線：熱液雜訊 ≥ 0.6 的段落 → **熱液噴口區**，其他 → **中洋脊**
   - 軸線兩側 1 格 → **中洋脊**
   - 離脊 3 格以上、海山雜訊 ≥ 0.93 → **深珊瑚礁**（冷水珊瑚長在海山頂上）
   - 其他 → **海床平原**

海洋層的細分和地表一樣（10），每個海洋格正好在一個地表格下方，格子 ID 也一一對應。
- **找正下方的海洋格**用 `OceanWorldView.TileBelow`：細分相同時直接用同一個 ID。原版的 `GetClosestTile_NewTemp` 在這種情況常常回傳鄰格（正下方是陸地，卻拿到旁邊的海）。升降井、放置檢查與測試都改用它。
- 舊存檔保留存檔裡的細分（7），所以舊世界沒有新的地形，要開新世界。

測試世界（quicktest，每次隨機）的一次分布：陸塊 61132、海床平原 37883、極地冰蓋 11743、深珊瑚礁 3907、海藻林 1838、淺珊瑚礁 1630、中洋脊 1043、深淵海溝 392、熱液噴口區 336。中洋脊軸線 648 格，活動邊緣海岸 547 格。
平均深度：中洋脊 2842 m、深海平原 5068 m、海溝 7860 m。

## 新的東西

- **珊瑚岩**（`DepthRim_CoralRock`，淺色，貼圖 `Thing/coralWall`）與 **深色珊瑚岩**（`DepthRim_DarkCoralRock`，貼圖 `Thing/coralWallDark`）
  - 天然岩體，只透過生態區的 `forceRockTypes` 出現。`mineablePreventNaturalRockOnSurface` 保證它不會隨機出現在地表地圖。
  - 開採得到珊瑚石塊，切成珊瑚磚（stuff）：淺色比較美觀，深色比較堅固。
- **海床淤泥**（`DepthRim_Seabed_Silt`，肥沃度 1.0）：海藻林與珊瑚礁的底質。
- **海藻**（`DepthRim_Kelp`）：光照下限 0，水下沒有天光也能長。採收得到生海藻（食物）。貼圖暫時借用原版的草並上色。
- **抗壓水密牆**（`DepthRim_PressureHullWall`，貼圖 `Thing/ShipHull`）
  - 造價鋼 12、塑鋼 3，900 HP。
  - 受損時滲水量只有一般牆的 1/10。
  - 帶有 `pressureRating = Seabed`，之後潛艇的耐壓船殼會讀這個值。
- **`LeakResistanceExtension`**：牆或門的受損滲水倍率改由 Def 設定。水密門 0.25、抗壓水密牆 0.1。
- **熱液泉散佈**（`GenStep_OceanVents`）：原版的間歇泉散佈步驟不放在水域生態區，也需要大片空地，所以自己寫了一個。

## 測試

- **單元測試**
  - `OceanBiomes`：分配規則的每一條，包括極地優先、海岸不放熱液、偏離中線就不是海溝，以及沒有地表資料時的退路。
  - `ContentOcean`：七種生態區各一個 BiomeDef，都有 `WaterMapExtension`、水深層級和 `forceRockTypes`；升降井到得了和到不了的生態區都存在；三張牆體貼圖都存在而且都有 Def 使用；舊的冰洋檔案已經移除。
- **驗收測試**
  - **L1**：海洋格子都是海洋生態區、至少五種、冰原與海冰下方是極地冰蓋（抽樣）。
  - **V16**：七種生態區各生成一張 100 × 100 的地圖，檢查水深層級、水位系統、只出現該生態區的岩石、珊瑚只在珊瑚礁、海藻、熱液泉、深淵比例，並截圖。
    - 測試地圖上要先放一段玩家電線，否則海洋地點會自己移除地圖。
  - **V17**：抗壓水密牆圍出密閉艙室，受損滲水約為一般牆的 1/10；升降井在極地冰蓋與深珊瑚礁上可以蓋，在海床平原上不行。
- **測試夾具**
  - 測試世界的開局地點是隨機的，所以把殖民地正下方的海洋格固定成極地冰蓋，讓既有測試仍然在淺海。
  - 測試區的山頂屋頂先拿掉。這修好了 E1 偶發的「shaft spawned=False」：岩體挖掉後山頂坍塌，坍下來的岩石把升降井整個抹掉了。

## 世界地圖上的海洋地形（2026-11-08）

切到海洋層時，世界地圖會畫出實際的海床地形，不再是一片空白。

- **生態區貼圖**：每個生態區都有自己的 `texture`（`Textures/World/Biomes/DepthRim/<生態區>.png`，512×512 無縫貼圖）。這些貼圖由 `.source/Tools/gen_ocean_biome_tex.py` 程式生成（`python -I .source/Tools/gen_ocean_biome_tex.py Textures/World/Biomes/DepthRim`），是原型用的暫代貼圖。
  - 極地冰蓋是淡藍冰面加裂紋。海藻林是墨綠色。淺珊瑚礁是青綠色加沙地與粉色珊瑚。深珊瑚礁是深藍紫色。
  - 海床平原是灰藍色沉積物。熱液噴口區是暗色岩上的橘色裂隙。深淵海溝近乎全黑。
- **海床深度**（`OceanBiomeSelector.SeafloorDepth`）：深度雜訊在每一段的範圍內取值，再夾進生態區的 `WaterMapExtension.seafloorDepth`（保險用）。
  - 深度存成負的 `Tile.elevation`，地形分頁的「高度」顯示例如 `-4200m`。
  - 陸塊照抄正上方地表格的高度、地勢與溫度。

| 離岸 | 被動邊緣 | 深度（m） | 活動邊緣 | 深度（m） |
|---|---|---|---|---|
| 0（冰原下） | 冰棚 | 100–500 | 冰棚 | 100–500 |
| 1 | 大陸棚內緣 | 10–80 | 大陸棚 | 10–120 |
| 2 | 大陸棚外緣 | 60–180 | 大陸坡上段 | 250–1000 |
| 3 | 大陸坡上段 | 250–700 | 大陸坡下段 | 1000–2000 |
| 4 | 大陸坡下段 | 650–1250 | 海溝 | 6000–8000 |
| 5 | 大陸隆堤 | 3000 起 | 海溝軸線 | 7500–11000 |
| 再往外 | 3 格內過渡到洋盆深度 | | 從 5500 m 過渡到洋盆深度 | |

- **洋盆深度**（`BasinDepth`）：中洋脊軸線 2500 m，離脊越遠越深（海洋地殼冷卻下沉）：`2500 + 3100 × (1 − e^(−離脊格數 / 8))`，8 格約 4500 m，趨近 5600 m；沒有中洋脊的洋盆是 5600 m。每格再加 ±250 m 的雜訊。
- **海山頂**：700–1500 m。

- **繪製圖層**（`WorldDrawLayers_Ocean.cs`）
  - `WorldDrawLayer_OceanTerrain`（原版地形層）、`WorldDrawLayer_OceanHills`、`WorldDrawLayer_OceanUngenerated`：只在選到海洋層時畫。
  - 不覆寫 `Visible`：原版看到「圖層可見且地形層是髒的」就開長事件重建，重建時又會跳過不可見的層，覆寫會變成每一幀都開長事件。
  - 海丘圖示的擺放照原版，但改用偏冷、半透明的材質：原版是陸地的褐色，畫在海床上像一座座小島。
- **水深著色**（2026-11-09，`WorldDrawLayer_OceanBathymetry.cs`，比照真實的海底地形圖）
  - 依每格的海床深度畫一層半透明的頂點顏色：淺水是亮而飽和的青藍，越深越暗、越偏深藍，海溝近乎黑。
  - 色階（`Bathymetry.ColorAt`）：0、40、200、1000、2500、4000、5500、7000、11000 m。淺處的間距比較密；2500–5500 m 也拉開了對比，中洋脊和深海平原才分得出來。
  - 頂點顏色取共用這個頂點的所有格子的平均深度，所以格子之間是平滑的漸層。
  - 覆蓋不透明度 190/255，生態區貼圖仍隱約可見。繪製順序在地形（3500）之後、海丘（3510）之前；這層不建碰撞體。
  - 舊存檔的格子沒有深度，改用生態區深度範圍的中間值著色。
  - 海丘圖示調成更淡（不透明度 0.42）：拉遠時原本會變成一片密密麻麻的點。
- **大陸**（2026-11-09，`WorldDrawLayer_OceanLand.cs`）：陸塊格畫成正上方的地表生態區（複製它的世界材質，繪製順序 3502），所以海洋層上看得出大陸與海岸線。
  - 陸塊不做水深著色，也不算進海岸頂點的平均，所以海岸線外緊鄰的是淺水的亮色。
  - 陸塊的地勢圖示用原版的褐色材質。
- **升降井**：正下方是陸塊時不能蓋（「陸地正下方沒有海洋。升降井只能挖穿冰原或海冰。」）。
- **看海洋時藏起地表**（`Patch_PlanetLayer_Visible`）：海洋層半徑 97，在地表（100）裡面，所以選到海洋層時其他圖層整層不畫，否則海床會被蓋住。
- **舊存檔**：世界格子在存檔裡，讀檔後的高度是 0（顯示 0m），開新世界才有深度。貼圖則是依生態區，舊存檔也會顯示。
- **測試**
  - 單元測試 `ContentOcean`：每個生態區的貼圖檔都存在、都有深度範圍，而且淺的生態區一定比深的淺。也檢查水深色階：每往深一階都更暗、一直是藍色、超出範圍時夾住。
  - 驗收測試 **L2**：所有格子都在海面以下、每個生態區的材質有貼圖。也檢查看地表時海洋地形不畫、看海洋時地表藏起來，以及水深著色的網格已建好。另外拍近景與拉遠的截圖。
